# Endpoint URL

<!-- shell@1 -->

This is the URL where the payment request is sent.

# Header

<!-- shell@2 -->

These are the headers that are sent with the request. The accept header specifies that the response should be in JSON format, while the Content-Type header specifies that the data being sent is in the x-www-form-urlencoded format.

# Request payload

<!-- shell@3-8 -->

This is the data that is being sent with the request. It includes the following parameters: 

key: This is the merchant key provided by PayU. 

txnid: This is the unique transaction ID generated by the merchant. 

amount: This is the amount of the transaction. 

firstname: This is the first name of the customer. 

email: This is the email address of the customer. 

phone: This is the phone number of the customer. 

productinfo: This is the product information. 

surl: This is the URL where the customer will be redirected after a successful transaction. 

furl: This is the URL where the customer will be redirected after a failed transaction. 

hash: This is the hash value generated by the merchant.
