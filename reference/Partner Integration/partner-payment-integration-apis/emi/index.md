Read EMI pricing and the cards that can pay by EMI.

* [Get EMI amount API](ref:partner-get-emi-amount-api) — EMI amount for a merchant and a transaction amount. Bank code and tenure can be sent with the request.
* [Get eligible EMI bins API](ref:partner-get-eligible-bins-api) — Bins that are eligible for EMI.
* [Calculate EMI API](ref:partner-calculate-emi-api) — Calculate EMI for a merchant. Amount and bank code can be sent with the request.
