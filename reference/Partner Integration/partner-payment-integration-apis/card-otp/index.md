Verify a card OTP, or send it again, for a partner card payment.

* [Submit card OTP API](ref:partner-submit-card-otp-api) — Submit the OTP for a `reference_id`. A verified OTP returns the transaction status and `mihpayid`.
* [Resend card OTP API](ref:partner-resend-card-otp-api) — Resend the OTP for the same `reference_id`.
