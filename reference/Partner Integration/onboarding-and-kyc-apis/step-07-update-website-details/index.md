---
title: Step 07 — Update or Skip Website Details
hidden: false
---
Adds the merchant's website URL and/or mobile app store URLs. You can skip website by mentioning "tools" in the **merchant\[integration_type]** parameter. The following are using the same API endpoint, but for skipping website details, you have to pass the additional parameter, `merchant[integration_type]` with the value, `tools` in the request.

* [Update Website Details API](https://docs.payu.in/reference/updatemerchant_websitedetails)
* [Skip Website Details API](https://docs.payu.in/reference/skip_merchant_website_details)

## Prerequisite Steps

Step 05 (Bank Details) or Step 06 (Bank Proof)

## Entity Applicability

**All entities**
