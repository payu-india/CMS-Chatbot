  # Utilities — Status Polling


  The GetMerchant API can be called **at any point between steps** to check the
  merchant's internal statuses. Use it to:


  - Verify PAN verification completed (after Step 02)

  - Check bank auto-verification result (after Step 05 — determines if Step 06
  is needed)

  - Check CKYC status (after Step 03 — determines DigiLocker requirement in Step
  09)

  - Check DigiLocker, VKYC status

  - Check KYC document verification status per document

  - Check agreement/E-sign status

  - Check overall onboarding stage and activation readiness
