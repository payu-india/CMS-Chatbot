#

Change wallet API is called by the calling application to change the wallet status on different aspects.

***

## Wallet Status Types

| Status      | Description                                                                                                                                                         |
| :---------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Active      | Wallet is in the active state, it can be used for all sorts of transactions.                                                                                        |
| Custom      | Wallet will be Custom Blocked (partial transactions will be allowed). Cashback and refund can be received. Load can be blocked while unload may work or vice versa. |
| Temporary   | Wallet will be Temporary Blocked (No transactions will be permitted)                                                                                                |
| Permanent   | Wallet will be permanently blocked                                                                                                                                  |
| Closed      | Wallet will be closed                                                                                                                                               |
| Debit       | All debits from the wallet will be temporarily blocked                                                                                                              |
| Credit      | All credits to the wallet will be temporarily blocked                                                                                                               |
| CreditDebit | All Credits and Debits will not be allowed, except system reversal credits and debits.                                                                              |
| Dormant     | Wallet will be in a dormant state. (same as temporary blocked)                                                                                                      |

***

## Request Parameters

| Parameter                        | Description                                                                                                      | Example        |
| :------------------------------- | :--------------------------------------------------------------------------------------------------------------- | :------------- |
| messageCode<br />`mandatory`     | `Numeric(4)` - API Unique Identifier                                                                             | 3530           |
| clientTxnId<br />`mandatory`     | `String(100)` - Unique ID generated by the calling application for each API request.                             | CBL-458        |
| requestDateTime<br />`mandatory` | `Numeric(14)` - Request local timestamp in YYYYMMDDHHMMSS with time in 24-hour format.                           | 20161011221416 |
| accountNumber<br />`mandatory`   | `String(15)` - Account Number uniquely identifies the customer's sub-wallet                                      | 2000123hh      |
| statusType<br />`mandatory`      | `String(10)` - Type of Block (Active, Custom, Temporary, Permanent, Closed, Debit, Credit, CreditDebit, Dormant) | Credit         |

***

## Response Parameters

| Parameter                            | Description                                                                 | Example                  |
| :----------------------------------- | :-------------------------------------------------------------------------- | :----------------------- |
| messageCode<br />`mandatory`         | `Numeric(4)` - API Unique Identifier.                                       | 3531                     |
| clientTxnId<br />`mandatory`         | `String(100)` - Value echoed from the request                               | BLOCK_JM_aax11LrjoCV-f34 |
| accountNumber<br />`mandatory`       | `String(20)` - Value echoed from the request                                | 30003958135_1            |
| accosaTransactionId<br />`mandatory` | `Numeric(10)` - Unique ID for a particular transaction generated in Prepaid |                          |
| description<br />`optional`          | `String(100)` - Reserved field to send information to client                | [Reserve_1]              |
| accosaRefNo<br />`mandatory`         | `Numeric(20)` - Auto-generated sequence number.                             | 52                       |
| responseCode<br />`mandatory`        | `String(2)` - Response code                                                 | 00                       |
| clientId<br />`mandatory`            | `String(10)` - Client ID                                                    | 2000                     |
| responseDateTime<br />`mandatory`    | `Numeric(14)` - Response timestamp                                          | 20230615234800           |
| responseMessage<br />`mandatory`     | `String(50)` - Response message                                             | SUCCESS                  |
| bankId<br />`mandatory`              | `Numeric(10)` - Bank ID                                                     | 7000                     |

***

## Sample Request

```bash
curl --location --request PATCH 'https://apitest.payu.in/loyalty-points/v1/wallet/onboarding/walletStatus' \
--header 'walletIdentifier: CLW' \
--header 'date: Wed, 12 Jun 2024 08:53:43 GMT' \
--header 'authorization: hmac username="smsplus", algorithm="sha512", headers="date", signature="v15rnvh1lnSEWRq6EW9BCfXlxO0QI/45xxmdxd2f4Q0="' \
--header 'Content-Type: application/json' \
--data-raw '{
  "messageCode": "3530",
  "clientTxnId": "CBL-458",
  "requestDateTime": "20161011221416",
  "accountNumber": "2000123hh",
  "statusType": "Credit"
}'
```
