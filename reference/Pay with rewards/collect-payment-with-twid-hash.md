The payment with rewards can be done with customer hash. This section describes the request and response parameters for payment with customer hash.

The customer hash is fetched when you collect payment from the customer using their mobile number for the first time. For more information, refer to [Collect Payment with Customer Mobile Number](https://devguide.payu.in/pay-with-rewards/pay-with-rewards-flows/collect-payment-with-customer-mobile-number-pay-with-rewards/).

## Sample Request

```curl
curl --location -g --request POST '{{baseUrl}}/_payment' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'hash=b7dff1b290afe4844456d7a5299c74ebc57211c51dff7378fad69038dad251c436ba1619ef5aeb1271141c7a06696029896976fc07037e7b84085a7ec5b0ee40' \
--data-urlencode 'key=hUmBue' \
--data-urlencode 'txnid=9750ba272c25a96581c5' \
--data-urlencode 'amount=10' \
--data-urlencode 'firstname=Payu-Admin' \
--data-urlencode 'salt_version=1' \
--data-urlencode 'email=test@example.com' \
--data-urlencode 'phone=1234567890' \
--data-urlencode 'productinfo=Product Info' \
--data-urlencode 'surl=http://admin.payu.in/test_response' \
--data-urlencode 'furl=http://admin.payu.in/test_response' \
--data-urlencode 'pg=CASH' \
--data-urlencode 'bankcode=TWID' \
--data-urlencode 'twid_customer_hash=aauieyra9723r973edbaibdc03yr92fbcuyajd0238479dq836973462ry32h8yr3297hf23'
```
