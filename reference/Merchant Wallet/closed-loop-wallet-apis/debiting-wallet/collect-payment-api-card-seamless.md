The **Seamless Debit Transaction** API allows you to debit funds from a wallet seamlessly through PayU payment gateway. This API provides a smooth user experience by handling the payment flow without redirecting the customer away from your application.

## Environment

| Environment | URL                               |
| ----------- | --------------------------------- |
| Test        | `https://test.payu.in/_payment`   |
| Production  | `https://secure.payu.in/_payment` |

**HTTP Method**: POST

## Request Headers

| Parameter                                | Description                                           |
| ---------------------------------------- | ----------------------------------------------------- |
| Content-Type<br /><code>mandatory</code> | <code>String</code> application/x-www-form-urlencoded |

## Request Parameters

| Parameter                                       | Description                                                                       | Example                                                   |
| ----------------------------------------------- | --------------------------------------------------------------------------------- | --------------------------------------------------------- |
| txnId<br /><code>mandatory</code>               | <code>Alphanumeric(25)</code> Unique transaction ID generated by the merchant     | 56882                                                     |
| key<br /><code>mandatory</code>                 | <code>Alphanumeric(50)</code> Merchant key provided by PayU during onboarding     | KPQwN8                                                    |
| productinfo<br /><code>mandatory</code>         | <code>Alphanumeric(100)</code> Brief description of the product                   | iPhone                                                    |
| Customer_id<br /><code>optional</code>          | <code>Numeric(50)</code> Unique ID for the customer (merchant's identifier)       | 89342546                                                  |
| walleturn<br /><code>optional</code>            | <code>Numeric(11)</code> Wallet URN generated by the system                       | 70000000008                                               |
| firstName<br /><code>mandatory</code>           | <code>String(60)</code> Customer's first name (only characters and single spaces) | Sourav                                                    |
| lastName<br /><code>optional</code>             | <code>String(60)</code> Customer's last name                                      | Mishra                                                    |
| phone<br /><code>mandatory</code>               | <code>Numeric(15)</code> Customer's phone number including ISD code               | 919988776655                                              |
| email<br /><code>mandatory</code>               | <code>String(50)</code> Customer email address                                    | [sourav.mishra@gmail.com](mailto:sourav.mishra@gmail.com) |
| ws_online_response<br /><code>mandatory</code>  | <code>String(255)</code> URL to redirect customer if transaction succeeds         | [https://success.url.com](https://success.url.com)        |
| ws_failure_response<br /><code>mandatory</code> | <code>String(255)</code> URL to redirect customer if transaction fails            | [https://failure.url.com](https://failure.url.com)        |
| amount<br /><code>mandatory</code>              | <code>Numeric(12)</code> Amount to debit in implied decimals (₹4.10 → 410)        | 4100                                                      |
| pg<br /><code>mandatory</code>                  | <code>String(10)</code> Set to 'CLW' for PayU's closed loop wallet                | CLW                                                       |
| txn_s2s_flow<br /><code>mandatory</code>        | <code>Numeric(1)</code> Constant value '4' to identify Seamless Debit             | 4                                                         |
| bankcode<br /><code>mandatory</code>            | <code>String(10)</code> Code indicating the PG used (merchant-specific)           | PAY                                                       |
| hash<br /><code>mandatory</code>                | <code>String(128)</code> SHA512 hash for request authentication                   | 6e640b...                                                 |

<Callout icon="📘" theme="info">
  Note: Either `Customer_id` or `walleturn` must be provided.
</Callout>

## Response Parameters

| Parameter     | Description                                        | Example                                                   |
| ------------- | -------------------------------------------------- | --------------------------------------------------------- |
| mihpayid      | Unique PayU-generated transaction reference number | 1735903830180094                                          |
| mode          | Payment method used                                | CLW                                                       |
| status        | Transaction status                                 | success                                                   |
| key           | Merchant key (echoed back)                         | KPQwN8                                                    |
| txnid         | Transaction ID (echoed back)                       | 56882                                                     |
| amount        | Transaction amount                                 | 10.00                                                     |
| productinfo   | Product description (echoed back)                  | iPhone                                                    |
| firstname     | Customer first name                                | Sourav                                                    |
| lastname      | Customer last name                                 | Mishra                                                    |
| email         | Customer email                                     | [sourav.mishra@gmail.com](mailto:sourav.mishra@gmail.com) |
| phone         | Customer phone number                              | 919988776655                                              |
| hash          | Response hash for verification                     | abc123...                                                 |
| PG_TYPE       | Payment gateway type                               | CLW                                                       |
| bank_ref_num  | Bank reference number                              | 123456789                                                 |
| error         | Error message (if any)                             | Insufficient balance                                      |
| error_Message | Detailed error message                             | Wallet balance is insufficient                            |

## Sample Request

### Encrypted Packet

```bash
curl --location --request POST 'https://test.payu.in/_payment' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'encdata=h/0YSUd9jKOQ8+2Dc3Phr4s7vxyz123...'
```

### Decrypted Packet

```
txnId=56882&key=KPQwN8&productinfo=iPhone&Customer_id=89342546&firstName=Sourav&lastName=Mishra&phone=919988776655&email=sourav.mishra@gmail.com&ws_online_response=https://success.url.com&ws_failure_response=https://failure.url.com&amount=4100&pg=CLW&txn_s2s_flow=4&bankcode=PAY&hash=6e640b...
```

## HTTP Status Codes

| Status Code | Description                              |
| ----------- | ---------------------------------------- |
| 200         | OK - Request processed successfully      |
| 400         | Bad Request - Invalid request parameters |
| 401         | Unauthorized - Authentication failed     |
| 500         | Internal Server Error                    |
