The **Retrieve Customer Record** API allows you to fetch customer details using various identifiers such as customerId, mobileNumber or urn.

## Environment

| Environment | URL                                                                   |
| ----------- | --------------------------------------------------------------------- |
| Test        | `https://apitest.payu.in/loyalty-points/v1/wallet/retrieveCustRecord` |
| Production  | `https://api.payu.in/loyalty-points/v1/wallet/retrieveCustRecord`     |

**HTTP Method**: POST

## Sample Request

```curl
curl --location 'https://apitest.payu.in/loyalty-points/v1/wallet/retrieveCustRecord' \
--header 'walletIdentifier: CLW' \
--header 'authorization: hmac username="Merchant_Key", algorithm="hmac-sha256", headers="date digest", signature="9h+PZ/ocY2ovWEF8ehvbNF9VDuz/wCIToMtO75oVE3Y="' \
--header 'date: Thu, 15 Oct 2026 11:10:44 GMT' \
--header 'Content-Type: application/json' \
--header 'Cookie: PHPSESSID=s4uujktf7gm484pt7uk7bdhv55; USERTXNINFO=6a4ce9368d6b52.40212033' \
--header 'Digest: p8V80K7BOrKq2L9pEtU+TuxW8gF7DPJdYniMqXFkcCY=' \
--data '{
"messageCode":1930,
"clientTxnId": "Test_93009874",
"requestDateTime": "20260901184938",
"customerMobile": "918954957892"
}'
```

## Response Parameters

| Parameter             | Description                                                                         | Example        |
| :-------------------- | :---------------------------------------------------------------------------------- | :------------- |
| `customerId`          | Unique identifier for the customer.                                                 | 000000330412   |
| `responseCode`        | Response status code.                                                               | 00             |
| `messageCode`         | API response code.                                                                  | 1931           |
| `clientTxnId`         | Mirrors the request's clientTxnId.                                                  | Test_93009874  |
| `clientId`            | Client identifier assigned by PayU.                                                 | 3000           |
| `responseDateTime`    | Timestamp of the response in YYYYMMDDHHmmss format.                                 | 20261015164044 |
| `accosaTransactionId` | Internal transaction ID generated by Accosa.                                        | 693965         |
| `responseMessage`     | Response message.                                                                   | SUCCESS        |
| `bankId`              | Identifier of the bank associated with the wallet.                                  | 6050           |
| `profileId`           | Profile identifier of the customer.                                                 | 30             |
| `mobile`              | Customer mobile number.                                                             | 9189549578920  |
| `firstName`           | Customer first name.                                                                | Shubham        |
| `lastName`            | Customer last name.                                                                 | Tyagi          |
| `dob`                 | Date of birth of the customer.                                                      |                |
| `kycName`             | KYC type of the customer.                                                           | MIN KYC        |
| `riskCategory`        | Risk classification of the customer.                                                | LOW_RISK       |
| `riskScore`           | Numerical risk score of the customer.                                               | 12             |
| `rekyc`               | Indicates if re-KYC is required.                                                    | false          |
| `dormancy`            | Indicates if the account is dormant.                                                | false          |
| `rekycValidity`       | Validity date for re-KYC.                                                           | 13-10-2036     |
| `form60`              | Indicates if Form 60 has been submitted.                                            | false          |
| `panValid`            | Indicates if the PAN is valid.                                                      | false          |
| `cardList`            | List of cards linked to the customer. Refer to the [cardList Object](#cardlist-json-object)| Array          |
| `enableVideoKyc`      | Indicates if video KYC is enabled for the customer.                                 | false          |
| `kycType`             | KYC completion type of the customer.                                                | MIN_COMPLETED  |

### cardList JSON Object

| Parameter              | Description                                                                                               | Example            |
| :--------------------- | :-------------------------------------------------------------------------------------------------------- | :----------------- |
| `cardNumber`           | Masked card number.                                                                                       | 100004 XXXXXX 2603 |
| `lastFourDigit`        | Last four digits of the card.                                                                             | 2603               |
| `entityName`           | Name of the entity associated with the card.                                                              | PAYU               |
| `cardType`             | Type of the card.                                                                                         | TRAVEL CARD        |
| `profileId`            | Profile ID associated with the card.                                                                      | 0                  |
| `cardStatus`           | Status code of the card.                                                                                  | 0                  |
| `availableBalance`     | Available balance on the card.                                                                            | 0                  |
| `createdOn`            | Date the card was created.                                                                                | 13-Oct-2026        |
| `updatedOn`            | Date the card was last updated.                                                                           | 13-Oct-2026        |
| `urn`                  | Unique reference number for the card.                                                                     | 1009650            |
| `statusDescription`    | Human-readable status of the card.                                                                        | Active             |
| `transactionProfiles`  | List of transaction profiles linked to the card. Refer to [transactionProfiles Object](#transactionprofiles-json-object). | Array              |
| `subwalletListDetails` | List of sub-wallets linked to the card. Refer to the [subwalletListDetails](#subwalletlistdetails-json-object) Object table below.         | Array              |
| `uniqueNumberValidity` | Validity period of the card's unique number (MMYY).                                                       | 1031               |
| `cardLinked`           | Indicates if the card is linked.                                                                          | false              |

### transactionProfiles JSON Object

| Parameter               | Description                                                                          | Example  |
| :---------------------- | :----------------------------------------------------------------------------------- | :------- |
| `transactionProfileId`  | Unique identifier for the transaction profile.                                       | 1        |
| `status`                | Indicates if the transaction profile is active.                                      | false    |
| `transactionType`       | Type of transaction. Possible values: `e-Com`, `POS`, `ATM`, `NFC_CARD_BASED`.       | e-Com    |
| `transactionRegionName` | Region applicable for the transaction. Possible values: `DOMESTIC`, `INTERNATIONAL`. | DOMESTIC |

### subwalletListDetails JSON Object

| Parameter           | Description                                         | Example         |
| :------------------ | :-------------------------------------------------- | :-------------- |
| `subwallet_id`      | Unique identifier for the sub-wallet.               | 3005cabc37e_1   |
| `default_wallet`    | Indicates if this is the default wallet. `1` = Yes. | 1               |
| `available_balance` | Available balance in the sub-wallet.                | 0               |
| `account_number`    | Account number of the sub-wallet.                   | 605030003190294 |
| `account_status`    | Status code of the sub-wallet account.              | 0               |
| `subwallet_name`    | Name of the sub-wallet.                             | General         |
| `accountValidity`   | Validity date of the sub-wallet account.            | 13-10-2027      |
