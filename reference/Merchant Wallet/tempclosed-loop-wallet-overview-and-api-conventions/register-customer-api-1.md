This API serves as the core component for registering new customers and facilitating the creation of digital wallets on Prepaid Platform. This API will do the following:

1. Register customer.
2. Perform onboarding check (whenever Applicable or opted by the Issuer).

***

## Sample Request

```bash

--header 'walletIdentifier: CLW' \
--header 'date: Wed, 12 Jun 2024 08:53:43 GMT' \
--header 'authorization: hmac username="smsplus", algorithm="sha512", headers="date", signature="v15rnvh1lnSEWRq6EW9BCfXlxOOQI/4Sxxmdxd2f4Q0="' \
--header 'Content-Type: application/json' \
--data-raw '{
  "messageCode": "3510",
  "clientTxnId": "20150701235959xhstiesqfds",
  "requestDateTime": "20161031214559",
  "customerId": "89342546",

    "firstName": "Sourav",
```
