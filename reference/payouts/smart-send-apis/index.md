The Smart Send APIs allows you to make a transfer instantly using a weblink. You can share the link with the beneficiary, make transfer based on the details entered by the beneficiary. This includes following APIs:

- [Create Smart Send Link API](ref:create-smart-send-link-api)
- [Smart Send Details API](ref:smart_send_details_api)
- [Extend Expiry Date API](ref:extend-expiry-date-api)
- [Cancel Smart Send API](ref:cancel-smartsend-api)

For the list of error messages and their description that you may encounter when Smart Send APIs integration, refer to [Smart Send Error Codes](ref:smart-send-error-codes)
