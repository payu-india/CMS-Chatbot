The Payouts Initiation and Tracking APIs allow you to get merchant account details, initiate, track and cancel payouts. It contains the following APIs:

- [Get Account Details API ](ref:get-account-details-api-payouts)
- [Initiate Transfer API](ref:initiate-transfer-api)
- [Check Transfer Status API](ref:check-transfer-status-api)
- [Cancel Transfer API](ref:cancel-transfer-api)
- [Disable Queued Payouts API](ref:disable-queued-payouts-api)
