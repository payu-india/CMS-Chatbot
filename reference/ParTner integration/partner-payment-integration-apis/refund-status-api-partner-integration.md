### Failure scenarios

- Invalid partner
- Error code=**400**

Status : BAD\_REQUEST(400)

```plaintext
{
    "message": "Partner with UUID 121**12213r is not allowed to do this action"
}
```

- Invalida auth token
- Error code=**401**

```plaintext
{
    "message": "Invalid Auth token"
}
```

- Invalid hash
- Error code=**403**

```plaintext
{
    "message": "Invalid Hash"
}
```

- Invalid PayU ID
- Error code=**400**

STATUS: BAD\_REQUEST(400)

```plaintext
{
    "40399**15528864745": {
        "errorCode": "400",
        "description": "0 out of 1 Transactions Fetched Successfully",
        "category": "RefundService",
        "data": ""
    }
}
```

- Any other issues in middleware

Response Status: INTERNAL\_SERVER\_ERROR(500)

```plaintext
{
    "message": "PayU Internal Server Error"
}
```
