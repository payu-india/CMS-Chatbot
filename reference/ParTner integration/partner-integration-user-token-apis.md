The following APIs are used as user tokens in the various Partner Integration APIs:

> 📘 Note:
>
> The various Partner Integration APIs use the user token in the header in the API command. The following APIs needs to be used in combination to get the user tokens.

* [Get Token API](https://docs.payu.in/reference/get_token_api)
* [Refresh Token API](https://docs.payu.in/reference/refresh_token_api)
* [Send OTP API](ref:send_otp_api)
* [Verify OTP API](ref:verify_otp_api)
