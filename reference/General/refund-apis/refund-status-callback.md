## Response Parameters Description

| Parameter | Description | Source Data |
|-----------|-------------|-------------|
| merchantTxnId | (string) Merchant Sale transaction id (max 50 chars) |  |
| mihpayid | (string) payuid (max 255 chars) | Var1 for refund initiate API |
| bank_arn | (string) Reference number for refund tracking (max 45 chars) |  |
| bank_ref_num | (string) Bank reference number (max 255 chars) |  |
| request_id | (string) Unique refund id generated by payu (max 255 chars) |  |
| token | (string) Unique refund txn id provided by merchant (max 23 chars) | Var2 for refund initiate API |
| action | (string) refund (max 32 chars) |  |
| amt | (string) Refund amount (max 65 chars) | Var3 for refund initiate API |
| status | (string) Status of the refund (max 32 chars) | Possible values: success/failure |
| additionalValue1 | For future scope |  |
| additionalValue2 |  |  |
| key | (string) Merchant key (max 20 chars) |  |
