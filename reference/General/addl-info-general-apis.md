## JSON Field description for transaction\_details parameter

The **transaction\_details** parameter of the response is in JSON format for the  **Check Refund Status** with Request ID/PayU ID, **Get Transaction Details** APIs, or **Verify Payment** APIs. The fields in this JSON are described in the following table:
