The Settlement Details API is used to retrieve settlement details which the bank has to settle you. The input is the date for which settlement details are required, where the var1 parameter is the date you want to know the settlement status or UTR (Unique Transaction Reference number). For more information, refer to [Get Settlement Details API](ref:get_settlement_details_api) API.
