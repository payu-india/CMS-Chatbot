---
name: V2_payment_response
---
| Parameter   | Description                                           |
| ----------- | ----------------------------------------------------- |
| referenceId | The reference ID sent in the request                  |
| paymentId   | Unique payment ID generated by PayU                   |
| status      | Payment status. Usually "PENDING" for hosted checkout |
| message     | Status message describing the payment state           |
| paymentUrl  | URL to redirect customer for payment completion       |
| orderId     | Order ID (returned when createOrder is enabled)       |
