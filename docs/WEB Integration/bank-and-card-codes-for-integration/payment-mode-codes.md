The following table provides the codes for each payment mode that must be used in various API integrations with PayU. In Merchant Hosted Checkout integration, these codes must be used with the **pg** parameter.

| **Payment Mode**    | **Code** |
| ------------------- | -------- |
| Net Banking         | NB       |
| Credit Card         | CC       |
| Debit Card          | DC       |
| Cash Card or Wallet | CASH     |
| UPI                 | UPI      |
| EMI                 | EMI      |
| EFTNET (NEFT/RTGS)  | NEFTRTGS |
| BNPL                | BNPL     |
| QR                  | QR       |
| Pay with Rewards    | LR       |
