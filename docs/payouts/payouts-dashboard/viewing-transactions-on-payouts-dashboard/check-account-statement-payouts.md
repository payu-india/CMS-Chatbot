Merchant can view the details of the financial transactions done within a period using Payouts Dashboard. You can download the account statement to analyse the transactions.

To view and download the account statement:

1. Click the **Account Statement** tab.

   The corresponding details are displayed on the **Account Statement** tab.

![](https://devguide.payu.in/wordpress/wp-content/uploads/2021/08/image-221-1024x765.png)

2. Select the period or date range using the **Date** filter to view the transactions. Make sure you click **Apply** button to save the changes.

![](https://devguide.payu.in/wordpress/wp-content/uploads/2021/08/image-226-1024x803.png)

3. Click **Download** button to download the statement in CSV (Comma Separated Values)or xlsx (Excel) format.

![](https://devguide.payu.in/wordpress/wp-content/uploads/2021/08/image-225-1024x753.png)
