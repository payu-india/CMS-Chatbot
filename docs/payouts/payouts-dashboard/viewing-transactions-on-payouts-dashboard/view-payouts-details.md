You can view the details of the payout for a selected duration. By default, it displays the payouts done in the past seven days. However, you can update the duration as per your requirement and analyze the data.

To view the payout details for a selected duration:

1. Click the **Payouts** tab to view the corresponding details.

![](https://devguide.payu.in/wordpress/wp-content/uploads/2021/08/image-229-1024x635.png)

2. Select the period or date range using the **Date** filter to view the transactions.

![](https://devguide.payu.in/wordpress/wp-content/uploads/2021/08/image-230-1024x635.png)

3. Sort the Payouts details as per the status of transaction using **Filter** button.

![](https://devguide.payu.in/wordpress/wp-content/uploads/2021/08/image-228.png)

4. Search payouts details associated with a particular Merchant Reference ID.

![](https://devguide.payu.in/wordpress/wp-content/uploads/2021/08/image-231-1024x636.png)

5. Click **Download** button to download the Payouts report in the CSV (Comma Separated Values) or XLSX (Excel) file format.

![](https://devguide.payu.in/wordpress/wp-content/uploads/2021/08/image-232-1024x636.png)
