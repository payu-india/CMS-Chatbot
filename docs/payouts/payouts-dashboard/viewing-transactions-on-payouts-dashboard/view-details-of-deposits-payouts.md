You can view the details of deposits done in a specific period using the Payouts Dashboard.

To view the details of deposits:

1. Click the **Deposits** tab to view the details of the deposits.

![](https://devguide.payu.in/wordpress/wp-content/uploads/2021/08/image-233-1024x591.png)

2. Select the period or date range using the **Date** filter to view the transactions.

![](https://devguide.payu.in/wordpress/wp-content/uploads/2021/08/image-236-1024x448.png)

3. Click **Download** button to download the Payouts report in CSV (Comma Separated Values) or xlsx (Excel) file format.

![](https://devguide.payu.in/wordpress/wp-content/uploads/2021/08/image-238-1024x449.png)
