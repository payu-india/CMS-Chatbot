Onboard merchants manually through the PayU dashboard.

Dashboard steps for the following:

1. Log in to [partner.payu.in](https://partner.payu.in/)
2. **Refer a Merchant** — Add Single Merchant or Add Multiple Merchants (CSV)
3. Merchant fields: name, email, phone, business category
4. Optionally complete the merchant profile on their behalf
5. Portal capabilities: transaction summaries, settlement reports, chargebacks, incentives, user management
