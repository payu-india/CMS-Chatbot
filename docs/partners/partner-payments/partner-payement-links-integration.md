Partner Payment Links enable partners to create shareable payment URLs on behalf of their merchants. These links can be sent via SMS, WhatsApp, email, or any messaging channel, allowing customers to pay without visiting a website.

## How it works?

Partner Payment Links use the same OAuth authentication flow as Partner Payments but with the `partner_payment_links` scope. Here's the complete flow:

1. **Authentication** — Generate OAuth access token with `create_payment_links` and `partner_payment_links` scopes
2. **Create Payment Link** — Call the payment links API with transaction details and hash
3. **Share Link** — Receive a unique URL that you can share with customers via any channel
4. **Customer Payment** — Customer opens the link and completes payment on PayU's hosted page
5. **Webhook Notification** — Receive real-time payment status updates via webhooks
6. **Verification** — Verify payment status using the verify payment API

Before you begin, ensure you have:

## Step 1: Generate OAuth Access Token

You must obtain an OAuth access token with the `partner_payment_links` scope before creating payment links.

### OAuth Scopes Required

When requesting the authorization code (Step 2 of OAuth flow), include these scopes:

```
create_payment_links partner_payment_links partner_payments
```

**Authorization Code Request Example:**

```bash
curl --location 'https://uat-partner.payu.in/api/v1/merchants/auth_code' \
--header 'Authorization: Bearer <ACCESS_TOKEN_FROM_STEP_1>' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'merchant_id=8739528' \
--data-urlencode 'reseller_uuid=11ee-0e7e-5403fde2-9523-0a696b110fde' \
--data-urlencode 'redirect_uri=https://uat-partner.payu.in' \
--data-urlencode 'scopes=create_payment_links partner_payment_links partner_payments'
```

<Info>
For the complete OAuth token generation flow, refer to [Partner Payments Integration Guide - Step 1](doc:partner-payments-integration-guide#step-1-generate-oauth-access-token).
</Info>

### Hash Generation Formula

Use the same hash formula as Partner Payments:

```
merchant_id|txnid|amount|productinfo|firstname|email|udf1|udf2|udf3|udf4|udf5||||||client_secret
```

<Warning>
**Important:**
- Six consecutive pipe characters (`||||||`) between `udf5` and `client_secret`
- Use OAuth `client_secret`, **not** merchant salt
- Compute SHA-512 and convert to lowercase hexadecimal
</Warning>

```python
import requests
import hashlib
import time

def create_payment_link(customer_name, customer_email, customer_phone, amount, description):
    url = "https://test-partnerapilayer.payu.in/apilayer/partner/payments"
    
    # Generate unique transaction ID
    txnid = f"PL{int(time.time() * 1000)}"
    
    # Compute hash
    merchant_id = 8739528
    hash_string = f"{merchant_id}|{txnid}|{amount}|{description}|{customer_name}|{customer_email}|||||payment_link||||||YOUR_CLIENT_SECRET"
    payment_hash = hashlib.sha512(hash_string.encode('utf-8')).hexdigest()
    
    headers = {
        "Authorization": "Bearer 039e0d1d70f467f946e2d73bd43868df856cfaa352ea54591a76bfc4a08d3487",
        "Content-Type": "application/json"
    }
    
    payload = {
        "txnid": txnid,
        "amount": amount,
        "productinfo": description,
        "firstname": customer_name.split()[0],
        "lastname": customer_name.split()[-1] if len(customer_name.split()) > 1 else "",
        "email": customer_email,
        "phone": customer_phone,
        "merchant_id": merchant_id,
        "reseller_id": "11ee-0e7e-5403fde2-9523-0a696b110fde",
        "surl": "https://partner.example.com/payment/success",
        "furl": "https://partner.example.com/payment/failure",
        "curl": "https://partner.example.com/payment/cancel",
        "udf5": "payment_link",
        "hash": payment_hash
    }
    
    response = requests.post(url, headers=headers, json=payload)
    result = response.json()
    
    return {
        "txnid": txnid,
        "payment_link": result.get('redirectUri'),
        "status": "link_created"
    }

# Usage
link = create_payment_link(
    customer_name="Rajesh Kumar",
    customer_email="rajesh@example.com",
    customer_phone="919876543210",
    amount="1500.00",
    description="Invoice Payment - #INV12345"
)

print(f"Payment Link: {link['payment_link']}")
print(f"Transaction ID: {link['txnid']}")
```

## Step 4: Customer Payment Journey

Once the customer receives the payment link:

1. **Opens Link** — Customer clicks the payment link
2. **Redirected to PayU** — Opens PayU's secure hosted checkout page
3. **Selects Payment Method** — Chooses from Cards, Net Banking, UPI, Wallets, EMI, etc.
4. **Completes Payment** — Enters payment details and authenticates
5. **Receives Confirmation** — Gets payment confirmation on screen
6. **Redirected Back** — Redirected to your `surl` (success) or `furl` (failure) URL

***

## Step 5: Receive Payment Notification

After the customer completes payment, PayU sends notifications to two places:

### 5.1 Redirect URL Response (surl/furl)

PayU POSTs payment details to your success or failure URL:

```python
from flask import request

@app.route('/payment/success', methods=['POST'])
def payment_success():
    response_data = request.form.to_dict()
    
    # Verify response hash
    if not verify_response_hash(response_data):
        return "Invalid hash", 400
    
    # Extract payment details
    txnid = response_data['txnid']
    status = response_data['status']
    mihpayid = response_data['mihpayid']
    amount = response_data['amount']
    
    # Update your database
    update_payment_status(txnid, status, mihpayid)
    
    # Display success page
    return f"""
    <html>
      <body>
        <h1>Payment Successful!</h1>
        <p>Transaction ID: {txnid}</p>
        <p>Amount Paid: Rs. {amount}</p>
        <p>PayU Payment ID: {mihpayid}</p>
      </body>
    </html>
"""
```

## Step 6: Verify Payment

Always verify the final payment status using the verify payment API:

```python
import requests
import hashlib

def verify_payment(txnid, merchant_id, reseller_id, client_secret):
    url = "https://test-partnerapilayer.payu.in/apilayer/partner/verifyPayment"
    
    # Compute verify hash
    hash_string = f"{merchant_id}|verify_payment|{txnid}|{client_secret}"
    verify_hash = hashlib.sha512(hash_string.encode('utf-8')).hexdigest()
    
    headers = {
        "Authorization": "Bearer YOUR_ACCESS_TOKEN",
        "Content-Type": "application/json"
    }
    
    payload = {
        "txnid": txnid,
        "merchant_id": merchant_id,
        "reseller_id": reseller_id,
        "hash": verify_hash
    }
    
    response = requests.post(url, headers=headers, json=payload)
    return response.json()

# Usage
verification = verify_payment(
    txnid="PL28471834809170984",
    merchant_id=8739528,
    reseller_id="11ee-0e7e-5403fde2-9523-0a696b110fde",
    client_secret="YOUR_CLIENT_SECRET"
)

print(f"Payment Status: {verification['status']}")
print(f"PayU Payment ID: {verification['mihpayid']}")
```

## Payment Link Features

### Link Expiry

Payment links created through the Partner API remain active until the customer completes payment or you manually expire them.

**Default Behavior:**

- Links stay active indefinitely by default
- Can be accessed multiple times until payment is complete
- After successful payment, link becomes invalid

<Info>
To set custom expiry times or manage link lifecycle, contact PayU support to enable advanced payment link features.
</Info>

### Supported Payment Methods

Payment links support all PayU payment methods:

- **Cards** — Credit Cards, Debit Cards (Visa, Mastercard, RuPay, Amex)
- **Net Banking** — All major banks
- **UPI** — UPI ID, UPI QR, UPI Intent
- **Wallets** — Paytm, PhonePe, Amazon Pay, Mobikwik, Freecharge
- **EMI** — Card EMI, Cardless EMI (ZestMoney, LazyPay)
- **Pay Later** — Simpl, LazyPay, ZestMoney, PayLater
- **International Cards** — Visa, Mastercard (if enabled)

## Error Codes

| HTTP Status | Error Message           | Description                             | Resolution                                        |
| ----------- | ----------------------- | --------------------------------------- | ------------------------------------------------- |
| 400         | Invalid hash            | Hash validation failed                  | Verify hash formula and client_secret             |
| 401         | Auth token is not valid | Access token expired or missing scope   | Regenerate token with partner_payment_links scope |
| 403         | Scope not allowed       | partner_payment_links scope not enabled | Contact PayU to enable scope                      |
| 400         | Missing surl or furl    | Redirect URLs not provided              | Include surl and furl in request                  |

## Best Practices

### 1. Use Descriptive Transaction IDs

```python
# Good - Descriptive and unique
txnid = f"PL_INV12345_{int(time.time())}"

# Bad - Generic
txnid = "123456"
```

### 2. Include Customer Context in UDF Fields

```python
payload = {
    # ... other fields
    "udf1": "invoice_12345",
    "udf2": "customer_id_789",
    "udf3": "sales_rep_john",
    "udf4": "channel_whatsapp",
    "udf5": "payment_link"
}
```

### 3. Track Link Performance

```python
# Log link creation
log_payment_link_created(txnid, customer_phone, amount, channel="whatsapp")

# Log link clicks (on surl/furl)
log_payment_link_clicked(txnid, timestamp)

# Log payment completion
log_payment_completed(txnid, status, mihpayid)
```

### 4. Handle Link Expiry Gracefully

```python
from datetime import datetime

# Store creation timestamp
link_created_at = datetime.now()

# Check expiry before sharing (7 days example)
if (datetime.now() - link_created_at).days > 7:
    # Create fresh link
    link = create_payment_link(customer_details)
```

### 5. Implement Idempotency

```python
def get_or_create_payment_link(order_id):
    # Check if link already exists
    existing_link = db.get_payment_link(order_id)
    
    if existing_link and existing_link.status == "pending":
        return existing_link.payment_url
    
    # Create new link
    return create_payment_link(order_details)
```
