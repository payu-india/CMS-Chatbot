If you seeing the following screen while accessing Loyalty Edge, it indicates that Loyalty Edge is not enabled for you. To enable Loyalty Edge, contact your PayU Key Account Manager or [PayU Support](https://help.payu.in).

<Callout icon="📘" theme="info">
  **Reference**:

  After you enable Loyalty Edge, set up a Loyalty to get started. For more information, refer to [Set up a Loyalty](https://docs.payu.in/docs/launch-loyalty-program-using-dashboard/#step-1-setup-loyalty)
</Callout>
