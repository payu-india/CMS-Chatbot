## Understanding EMI Codes

EMI (Equated Monthly Installment) codes are used during checkout to identify payment options with installment plans.

### Key Components

* **Bank Name**: The financial institution offering the EMI option
* **Bank Code**: The code to use during transaction processing
* **Tenure**: The duration of the installment plan (in months)
* **Interest Rate**: The applicable interest on the transaction
* **Min Amount**: Minimum transaction value required for eligibility
* **Max Amount**: Maximum transaction value allowed (if applicable)
* **Processing Fee**: Standard fee charged for the EMI option
* **Min Processing Fee**: Minimum fee applicable regardless of percentage

For any questions regarding EMI options, please contact your bank directly.
