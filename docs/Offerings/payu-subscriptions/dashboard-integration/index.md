## Purpose

Enable merchants to run subscriptions using **PayU Dashboard** only — payment links, bulk CSV registration, and bulk recurring debits.

## When to use this

* No engineering resources for API integration
* Ad-hoc or low-volume recurring billing
* Operations team manages billing via CSV
