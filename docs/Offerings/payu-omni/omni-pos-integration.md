#### Mandatory Parameters

| Parameter | Type & Description | Example |
|---|---|---|
| <Glossary>accountId</Glossary> | **String**<br>Your PayU Merchant Account ID. | `smsplus` |
| <Glossary>txnId</Glossary> | **String**<br>Unique transaction ID generated by your billing system. | `POS_TXN_987654321` |
| <Glossary>amount</Glossary> | **Number / String**<br>Total payable amount in INR. | `100.00` |
| <Glossary>currency</Glossary> | **String**<br>ISO currency code. Must be `INR`. | `INR` |
| <Glossary>paymentSource</Glossary> | **String**<br>Payment channel identifier. Set to `POS` or `WEB`. | `POS` |
| <Glossary>paymentMethod</Glossary> | **Object**<br>Specifies the payment method object.<br>• `name`: `"POS"` *(Mandatory)*<br>• `bankCode`: `"POS"` *(Mandatory)* | `{"name": "POS", "bankCode": "POS"}` |
| `additionalInfo` | **Object**<br>Integration flow details.<br>• `txnFlow`: `"seamless"`<br>• `txnS2sFlow`: `"4"` | `{"txnFlow": "seamless", "txnS2sFlow": "4"}` |
| `omniChannelDetails` | **Object**<br>POS terminal routing details.<br>• `posDeviceId`: *(Mandatory, String)* Registered POS Device ID.<br>• `posPaymentMethod`: *(Optional, String)* Specific mode to enforce on device: `sale`, `qr`, `wallet`, `emi`, `preauth`. Leave blank to show all enabled modes.<br>• `userId`: *(Optional, String)* Cashier / operator identifier.<br>• `printInfo`: *(Optional, Object)* Key-value strings (e.g., `printInfo1`, `printInfo2`) to print on terminal receipt. | `{"posDeviceId": "134", "posPaymentMethod": "sale", "userId": "cashier_102"}` |
| `order` | **Object**<br>Order and pricing metadata.<br>• `productInfo`: *(Optional, String)* Product or order description.<br>• `paymentChargeSpecification.price`: *(Mandatory, Number/String)* Charge price (must match `amount`).<br>• <Glossary>userDefinedFields</Glossary>: *(Optional, Object)* Custom metadata fields (`udf1` to `udf5`). | `{"productInfo": "Store Purchase", "paymentChargeSpecification": {"price": "100.00"}}` |
| `callBackActions` | **Object**<br>Callback URL mappings.<br>• `successAction`: *(Mandatory, String)* Standard callback URL.<br>• `failureAction`: *(Optional, String)* Failure callback URL.<br>• `cancelAction`: *(Optional, String)* Cancel callback URL.<br>*Note: While offline POS transactions update primarily via webhooks, these URLs are required by the V2 API schema.* | `{"successAction": "https://your-domain.com/success"}` |

#### Optional Parameters

| Parameter | Type & Description | Example |
|---|---|---|
| `omniChannelDetails.posPaymentMethod` | **String**<br>Specific payment mode to enforce on the POS device. Accepted values: `sale`, `qr`, `wallet`, `emi`, `preauth`. Leave blank to display all enabled modes. | `sale` |
| `omniChannelDetails.userId` | **String**<br>Cashier or operator identifier for the transaction. | `cashier_102` |
| `omniChannelDetails.printInfo` | **Object**<br>Key-value string pairs to print on the terminal receipt (e.g., `printInfo1`, `printInfo2`). | `{"printInfo1": "Store Brand Name", "printInfo2": "MG Road, Bengaluru"}` |
| `order.productInfo` | **String**<br>Product or order description. | `Store Purchase` |
| `order.userDefinedFields` | **Object**<br>Custom metadata fields (`udf1` to `udf5`) for merchant-defined data. | `{"udf1": "Store_MG_Road", "udf2": "POS_Terminal_01"}` |
| `callBackActions.failureAction` | **String**<br>URL to redirect or notify on payment failure. | `https://your-domain.com/failure` |
| `callBackActions.cancelAction` | **String**<br>URL to redirect or notify on payment cancellation. | `https://your-domain.com/cancel` |
| <Glossary>gstParams</Glossary> | **Object**<br>GST & Tax breakup details. Accepted fields: `invoiceNo`, `invoiceDate`, `gstIn`, `cgst`, `sgst`, `igst`, `cess`. | `{"invoiceNo": "INV001", "cgst": "9.00", "sgst": "9.00"}` |

import java.io.OutputStream;
import java.net.HttpURLConnection;
import java.net.URL;
import java.nio.charset.StandardCharsets;
import java.time.ZonedDateTime;
import java.time.ZoneOffset;
import java.time.format.DateTimeFormatter;

public class PayUPosPayment {
    public static void main(String[] args) {
        try {
            URL url = new URL("<YOUR_API_ENDPOINT_URL>");
            HttpURLConnection conn = (HttpURLConnection) url.openConnection();
            conn.setRequestMethod("POST");
            conn.setRequestProperty("Content-Type", "application/json");
            conn.setRequestProperty("date", DateTimeFormatter.RFC_1123_DATE_TIME.format(ZonedDateTime.now(ZoneOffset.UTC)));
            conn.setRequestProperty("authorization", "YOUR_GENERATED_AUTH_HEADER");
            conn.setDoOutput(true);
            String jsonInputString = "{"
                + "\"accountId\": \"smsplus\"," 
                + "\"txnId\": \"POS_TXN_987654321\"," 
                + "\"amount\": 100.00,"
                + "\"currency\": \"INR\"," 
                + "\"paymentSource\": \"POS\"," 
                + "\"paymentMethod\": {\"name\": \"POS\", \"bankCode\": \"POS\"},"
                + "\"additionalInfo\": {\"txnFlow\": \"seamless\", \"txnS2sFlow\": \"4\"},"
                + "\"callBackActions\": {\"successAction\": \"<YOUR_SUCCESS_CALLBACK_URL>\"},"
                + "\"order\": {\"productInfo\": \"Store Purchase\", \"paymentChargeSpecification\": {\"price\": \"100.00\"}},"
                + "\"omniChannelDetails\": {\"posDeviceId\": \"134\", \"posPaymentMethod\": \"sale\"}"
                + "}";
            try (OutputStream os = conn.getOutputStream()) {
                byte[] input = jsonInputString.getBytes(StandardCharsets.UTF_8);
                os.write(input, 0, input.length);
            }
            System.out.println("Response Code: " + conn.getResponseCode());
        } catch (Exception e) {
            e.printStackTrace();
        }
    }
}
