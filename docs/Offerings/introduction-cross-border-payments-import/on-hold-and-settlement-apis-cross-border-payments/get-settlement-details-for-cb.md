You must use the following APIs to get the settlements-related details for cross-border payment:

* [Settlement Detail Range API - CB Payments](ref:settlement-detail-range-api-for-cross-border):  This is build on top of settlement data that provides transaction level data for a given date or date range or UTR. This API returns paginated response for the given input page and page size.
* [Get Settlement Detail API - CB Payments](ref:get-settlement-detail-api-cross-border-payments).
