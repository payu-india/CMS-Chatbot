The following sections describe steps to integrate pre-authorize for card payments with various integrations:

* [PayU Hosted Integration](https://docs.payu.in/docs/payu-hosted-integration-pre-authorize-payments)
* Merchant Hosted Integration:
  * [Credit Card - Merchant Hosted Integration](https://docs.payu.in/docs/credit-card-merchant-hosted-integration-pre-authorize-payment)
  * [Debit Card - Merchant Hosted Integration](doc:debit-card-merchant-hosted-integration-preauthorize-payments)

<Callout icon="📘" theme="info">
  **Note**: The API integration for Auth and Capture will remain the same for Credit Card and Debit Card and only the pg and bankcode parameter values will vary accordingly.
</Callout>

  **Reference**: For cancelling Pre-Auth transactions, refer to the [Cancel a Pre-Authorized Transaction API](ref:cancel-a-pre-authorized-transaction).
</Callout>
