This integration will be done with PayU’s PG, so separate credentials/keys will be required to integrate.

The following keys required by merchant:

1. Merchant ID
2. Key
3. Salt

  **Note**: Payment Management includes the customer facing journeys which are during the purchase of a product/service on the merchant.
