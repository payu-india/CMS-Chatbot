## Filter the Payment Links

You can filter subscription payment links on Subscriptions Dashboard for a date range and/or payment link status.

To filter the subscription payment links on Subscriptions Dashboard:

1. Navigate to **Subscriptions** on the PayU Dashboard.
2. Select the **Links** tab.
3. Click the **Filter** drop-down menu to list the filter options similar to the following screenshot.

<Image align="center" border={true} src="https://files.readme.io/b5153461d6887913cc7abfc1f329f31e8adc26de6d335aa68fc53002e8ecf12e-Screenshot_2024-09-16_at_10.21.32_AM.png" className="border" />

4. Click to select any of the following check box from the **Filter** drop-down menu.

* Active
* Dashboard
* Expired

5. Click **Apply** to get the results.

<Callout icon="📘" theme="info">
  **Reference**: You can filter the subscription payment links by last week, month or by custom date range similar to Transactions Dashboard. For more information, refer to [View Transactions for a Custom Period](doc:view-transactions-for-a-custom-period).
</Callout>

<Callout icon="📘" theme="info">
  **Note**: You can use the **Reset** to clear all checkbox selections.
</Callout>

## View a Subscription Payment Link Details

You can view the details subscription payment link that was created using PayU Dashboard.

To view the details of a subscription payment link:

1. Navigate to the **Subscriptions** on PayU Dashboard.

   The **Links** tab is displayed on the right-pane by default.

2. Click the payment link row for which you wish to view the details.

The _Link Details_ page is displayed with the **Details** sub-tab selected similar to the following screenshot. The **Details** sub-tab displays the link details, plan details, and customer details.

<Image align="center" border={true} src="https://files.readme.io/2d85d8f810240bdc4b31d627fcaf5a7ada0b83489e136b4a96d25e1c3abcb9c9-dashboard-subscription-link-details.png" className="border" />

Click the **Subscriptions** sub-tab on this screen to view and download all the mandates created using that payment link along with status and plan details.

You can use the following button at the top-left to manage the payment link:

* **Deactivate Link**: For more information, refer to [Deactivate a Subscription Payment Link](doc:#deactivate-a-subscription-payment-link).
* **Duplicate Link**: For more information, refer to [Duplicate a Subscription Payment Link](doc:#duplicate-a-subscription-payment-link)
* **Share**: For more information, refer to [Share a Subscription Payment Link](doc:#share-a-subscription-payment-link).

## Deactivate a Payment Link

To deactivate a subscription payment link:

1. Navigate to the **Subscriptions** on PayU Dashboard.

2. Select the **Links** tab.

   The **Links** tab is displayed on the right-pane by default.

3. Click the **Actions** menu and select **Deactivate** for the payment link that wish to deactivate similar to the following screenshot.

<Image align="center" border={true} src="https://files.readme.io/b2a2c08e7808d9e940dc647d7a2051566983c2b4e10168691f6c7978ce8394df-Screenshot_2024-09-16_at_10.15.01_AM.png" className="border" />

A confirmation message is displayed similar to the following screenshot:

<Image align="center" border={false} src="https://files.readme.io/e99f714e014844e9078af095c07dd0923a403bcb0542ea4686222f4c519d1190-Screenshot_2024-09-16_at_10.16.14_AM.png" />

3. Click **Yes** to deactivate.

## Share a Payment Link

To share a subscription payment link to your customers:

1. Navigate to the **Subscriptions** on PayU Dashboard.

   The **Links** tab is displayed on the right-pane by default.

2. Click the **Actions** menu and select **Share** for the payment link that wish to deactivate similar to the following screenshot.

<Image align="center" border={true} src="https://files.readme.io/176eea40baca62a6865ac503a39438740d21d4ec21e5a50ede81715a7b545e22-Screenshot_2024-09-16_at_10.20.27_AM.png" className="border" />

The _Share Now_ pop-up page is displayed.

<Image align="center" border={false} src="https://files.readme.io/67de81d56724a3fcb234c9ec7dcd0b49d9b16e26aeb7d0df383b8bde3c506e6a-Screenshot_2024-09-02_at_4.15.14_PM.png" />

3. Enter the mobile numbers or email IDs separated by comma.
4. Click **Share**.

> 📘 Copying URL to share it with customers
>
> Click **Copy URL** to copy the URL and then share it with your customers.
