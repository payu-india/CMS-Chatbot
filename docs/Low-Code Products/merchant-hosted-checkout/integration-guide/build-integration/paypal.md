Activate PayPal from the PayU Dashboard before you post `pg=PAYPAL` and `bankcode=PAYPAL`. Settlements are in INR. Refunds need a PayPal balance.

<!-- VALIDATION NEEDED: The customer journey describes a PayU-hosted wallet list. The overview table says the PayPal bankcode is N/A. -->

***

## Prerequisites

Read [Build the Integration](./index). Enable PayPal on the Dashboard.

***

## Overview of Steps

1. Prepare `pg=PAYPAL` and `bankcode=PAYPAL`.
2. Generate the hash on the server.
3. Post the form.
4. Verify the reverse hash.
5. Call `verify_payment`.

***

## Build Integration Steps

### Step 1: Prepare Payment Request Parameters

Collect and structure the parameters below before you post a PayPal payment. Activate PayPal on the PayU Dashboard first.

<Tabs>
  <Tab title="Mandatory Parameters and Description">
    These are the mandatory parameters for PayPal.<br />

    | Parameter | Description |
    | --- | --- |
    | `key` | `string` Unique merchant key provided by PayU. For example, `8488225`. |
    | `txnid` | `varchar` Order reference generated by the merchant. Must be unique for every new transaction. For example, `fd3e847h2`. |
    | `amount` | `float` Payment amount. For example, `10`. |
    | `productinfo` | `varchar` Brief product description. For example, `T-shirt`. |
    | `firstname` | `varchar` Customer's first name. For example, `Ankit`. |
    | `email` | `varchar` Customer's email. For example, `test@gmail.com`. |
    | `phone` | `integer` Customer's phone number. For example, `9876543210`. |
    | `pg` | `string` Payment category. For this method, `PAYPAL`. |
    | `bankcode` | `string` Must be `PAYPAL`. |
    | `surl` | `string` Success URL PayU redirects to if the transaction is successful. For example, `https://apiplayground-response.herokuapp.com/`. |
    | `furl` | `string` Failure URL PayU redirects to if the transaction fails. For example, `https://apiplayground-response.herokuapp.com/`. |
    | `hash` | `string` SHA-512 hash from Step 2. Formula: `sha512(key\|txnid\|amount\|productinfo\|firstname\|email\|udf1\|udf2\|udf3\|udf4\|udf5\|\|\|\|\|\|SALT)`. |
  </Tab>
  <Tab title="Optional Advanced Parameters and Description">
    Send these optional parameters when you collect them.<br />

    | Parameter | Description |
    | --- | --- |
    | `lastname` | `string` Customer's last name. For example, `Kumar`. |
    | `address1` | `string` First line of the billing address. For example, `123 Main St`. |
    | `address2` | `string` Second line of the billing address. For example, `Apt 4B`. |
    | `city` | `string` Billing city. For example, `Mumbai`. |
    | `state` | `string` Billing state. For example, `Maharashtra`. |
    | `country` | `string` Billing country. For example, `India`. |
    | `zipcode` | `string` Billing zip code. The source says this is mandatory for cardless EMI. For example, `400001`. |
    | `udf1` | `string` Information you store against the transaction. For example, `custom_data_1`. |
    | `udf2` | `string` Information you store against the transaction. For example, `custom_data_2`. |
    | `udf3` | `string` Information you store against the transaction. For example, `custom_data_3`. |
    | `udf4` | `string` Information you store against the transaction. For example, `custom_data_4`. |
    | `udf5` | `string` Information you store against the transaction. For example, `custom_data_5`. |
  </Tab>
</Tabs>

### Step 3: Post the Payment Form

POST the parameters from Step 1 and the hash from Step 2 to `_payment`.

<Accordion title="POST the HTML Form (server renders)" icon="fa-paper-plane">
  <Cards>
    <Card title="Method">
      POST
    </Card>
    <Card title="Endpoint">
      /_payment
    </Card>
  </Cards>

  | Environment | URL |
  | --- | --- |
  | **Test** | `https://test.payu.in/_payment` |
  | **Production** | `https://secure.payu.in/_payment` |

  Post `pg=PAYPAL` and `bankcode=PAYPAL` with the fields in Step 1.
</Accordion>

<Accordion title="Success and Error Response" icon="fa-circle-check">
  Sample: `mode=PAYPAL`, `bankcode=PAYPAL`, `status=success`, `error=E000`, `field4=0.12`, `field5=USD`.
</Accordion>
