`pg=CASH` and the wallet `bankcode` from [Wallet Codes](https://docs.payu.in/docs/wallet-codes). The Paytm sample uses `PAYTM`. Advantage Club uses `pg=RD` and `bankcode=ADVCLUB`.

***

## Prerequisites

Read [Build the Integration](./index).

***

## Overview of Steps

1. Prepare `pg` and `bankcode`.
2. Generate the hash on the server.
3. Post the form.
4. Verify the reverse hash.
5. Call `verify_payment`.

***

## Build Integration Steps

### Step 1: Prepare Payment Request Parameters

Collect and structure the parameters below before you post a wallet payment. Use `pg=CASH` and the wallet `bankcode`. Advantage Club uses `pg=RD` and `bankcode=ADVCLUB`.

<!-- VALIDATION NEEDED: This page's table describes furl as the success URL and surl as the failure URL. The Paytm cURL uses lowercase cash and paytm. The overview says bank codes are case-sensitive. -->

<Tabs>
  <Tab title="Mandatory Parameters and Description">
    These are the mandatory parameters for a wallet payment. The wallets page does not split them into a separate optional table.<br />

    | Parameter | Description |
    | --- | --- |
    | `key` | `string` Merchant key provided by PayU during onboarding. For example, `JP***g`. |
    | `txnid` | `string` Transaction ID generated by the merchant for this order. For example, `ypl938459435`. |
    | `amount` | `string` Payment amount. For example, `10.00`. |
    | `productinfo` | `string` Brief description of the product. For example, `iPhone`. |
    | `firstname` | `string` Customer's first name. For example, `Ashish`. |
    | `email` | `string` Customer's email address. For example, `abc@payu.in`. |
    | `phone` | `string` Customer's phone number. For example, `9876543210`. |
    | `pg` | `string` Payment category. `CASH` for wallets. `RD` for Advantage Club. For example, `CASH`. |
    | `bankcode` | `string` Wallet code. See [Wallet Codes](https://docs.payu.in/docs/wallet-codes). The Paytm example is `PAYTM`. |
    | `surl` | `string` The source table calls this the failure URL. For example, `https://example.com/failure`. |
    | `furl` | `string` The source table calls this the success URL. For example, `https://example.com/success`. |
    | `hash` | `string` SHA-512 hash from Step 2. Formula: `sha512(key\|txnid\|amount\|productinfo\|firstname\|email\|udf1\|udf2\|udf3\|udf4\|udf5\|\|\|\|\|\|SALT)`. |

### Step 3: Post the Payment Form

POST the parameters from Step 1 and the hash from Step 2 to `_payment`.

<Accordion title="POST the HTML Form (server renders)" icon="fa-paper-plane">
  <Cards>
    <Card title="Method">

  </Cards>

  | Environment | URL |
  | --- | --- |
  | **Test** | `https://test.payu.in/_payment` |
  | **Production** | `https://secure.payu.in/_payment` |

  The HTML sample posts `pg=CASH` and `bankcode=PAYTM`. Advantage Club has no test environment. Its sample still shows `pg=RD` and `bankcode=ADVCLUB`.
</Accordion>
