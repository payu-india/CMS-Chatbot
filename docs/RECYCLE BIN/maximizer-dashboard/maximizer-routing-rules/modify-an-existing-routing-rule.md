To modify an existing routing rule:

1. Select the **Routing Rules** tab on the Maximizer Dashboard.

   The **Routing Rules** tab is displayed with existing rules.

<Image align="center" className="border" border={true} src="https://files.readme.io/965dd0c-Screenshot_2024-06-20_at_9.52.32_AM.png" />

<Image align="center" width="00px" src="https://files.readme.io/3e1f65b-Screenshot_2024-06-19_at_10.18.01_AM.png" />

2. Click the hamburger menu under Actions and select **Update**.

The *Manage Rule* page with the *Rule Configuration* screen is displayed. In this example, the Net Banking payment method is configured.

<Image align="center" className="border" border={true} src="https://files.readme.io/6301f61-Screenshot_2024-06-20_at_10.01.15_AM.png" />

3. Udate the payment types and click **Next**.

   The *Payment Aggregator* screen is displayed.
4. Select **Success Based Routing** tab (if required).
5. Remove the payment aggregators using the remove button (**X**) and then click **Next**.

   The *Rule Guidelines* screen is displayed.

<Image align="center" className="border" border={true} src="https://files.readme.io/e24c174-Screenshot_2024-06-19_at_11.00.09_AM.png" />

6. Enter the name for the rule in the **Title** field.
7. Click **Create Rule** to create the rule.

   The rule is added to the **Routing Rules** tab of Maximizer dashboard.
