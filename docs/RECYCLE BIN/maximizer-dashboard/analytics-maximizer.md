You can view Maximizer analytics on Dashboard for today or specific date range. Also, you can filter by aggregator or amount slab.

To view the Maximizer. analytics on Dashboard:

1. Log on to PayU Dashboard. For more information, refer to [Log in to Dashboard](doc:log-in-to-dashboard).
2. Select **Maximizer** from the menu on left-pane. 
3. Select the **Analytics** tab on the right pane.

```
   Step 2: Navigate to Maximzer Tab; click on Analytics Tab
```
