You can view the transactions details of payments on the PayU Dashboard by navigating to **Transactions** > **Payments**.  

> 📘 Payment Aggregator column for Maximiser:
>
> The **Payment Aggregator** column is enabled in the Transaction Overview page to view the payment aggregator source.

<Image align="center" className="border" border={true} src="https://files.readme.io/434dfe25d141737461e6f68c3ef45aeda96601ef2784eee7cd02f64f1380b671-maximiser_transactions_overview.png" />

If you view the transaction details, the payment aggregator source is displayed in the **Payment Aggregator** field.
