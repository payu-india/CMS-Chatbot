## Refunds

You can initiate the refunds from the PayU Dashboard or using the Refund APIs. To view the refund records on PayU Dashboard,  navigate to **Transactions** > **Refunds** tab.  For more information, refer to any of the following:

* [Refunds Dashboard](doc:refunds-dashboard)
* [Refund Transaction API](ref:refund_transaction_api).
