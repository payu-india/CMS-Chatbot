## How to use this report

* **Missing:** `description` = page has empty or no `metadata.description`; `keywords` = page has no `metadata.keywords` list (or empty). Many pages have both missing.
* **Suggested metadata:** Add under the `metadata:` block in each page’s frontmatter, for example:
  ```yaml
  metadata:
    title: <existing or from suggested description>
    description: '<suggested description from table>'
    keywords:
      - <keyword1>
      - <keyword2>
      - ...
    robots: index
  ```
* Use the **suggested search keywords** as a comma-separated list; for YAML, add each as a list item under `keywords:`.
* You can refine descriptions and keywords per page for tone and product naming consistency.
