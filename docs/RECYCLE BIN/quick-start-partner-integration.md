Get a merchant onboarded with a small set of API calls: create merchant, update PAN/bank/business, CKYC OTP, upload KYC documents, initialize e-sign.

> **Next:** The full flow includes CKYC OTP verification, DigiLocker, optional VKYC, and e-sign completion. See [API integration](doc:api-integration) and [CKYC, DigiLocker, and VKYC](doc:ckyc-digilocker-vkyc).
