The filter option enables you to filter the transactions by Source, Transaction Status, Payment Mode, and Outlets.

To filter the transactions on Dashboard:

1. Click the **Filter** menu to list the filter options.
2. Click to select the check box for the desired options from the **Filter** menu.
3. Click **Apply** to get the results.

> **Note:** You can use the **Reset** to clear all checkbox selections.
