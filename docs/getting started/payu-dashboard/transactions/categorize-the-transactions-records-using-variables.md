You can categorize the records view using the customize columns and filter options.

To customize the transaction records view using the variables:

1. Click to select the desired variable from the drop-down list to show the results by **Transaction ID, Customer email ID, Merchant Reference ID, Phone Number**, or **Customer Name**.
2. To search for a particular transaction, enter the particular transaction ID or any other variable listed above in the **Search** field.
3. Press the **Enter** key to get the results.
