To schedule certain reports:

1. Navigate to **Analytics > Reports**
2. Select **Generate Report** on any of the tile for which you want to schedule report.
3. Select the **Scheduled Reports** tab.

   The **Scheduled Reports** tab is displayed.![](https://devguide.payu.in/wordpress/wp-content/uploads/2021/08/image-103.png)
4. Select the desired **report type** from the drop-down list.
5. Click to select the **Start and End date** from the calendar view.
6. Select the desired frequency **Daily, Weekly** or **Monthly** from the drop-down list.
7. Select the preferred time for report generation from the drop-down list.
8. Select the required **Source, Payment method, or Transaction Status** options given in the **Filters** field.
9. Select the file format (CSV or XLSX) from the drop-down list
10. Enter the recipient email addresses in the **Enter Email** field to receive the report.

**Note**: Use the **Add Another Email** option to add more mail IDs, but the report can be scheduled only for two email IDs at a time.​

11. Click **Schedule** to complete the action.The history of downloaded and scheduled reports is available in this section. You can download them again using the download option using the options under the **Actions** menu.
