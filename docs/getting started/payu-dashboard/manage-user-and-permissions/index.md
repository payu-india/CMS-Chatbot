You can create and modify different roles and assign permissions. You can edit or delete the role and permissions under the **Manage Employee** or **Manage roles** tabs. Use the **Actions** menu and save the changes.

The following sections describes how to manage users and permissions on the PayU Dashboard:

* [Add a Role](https://docs.payu.in/docs/add-a-role)
* [Add an Employee](https://docs.payu.in/docs/add-an-employee)
* [Update an Employee Detail](https://docs.payu.in/docs/update-an-employee-detail)
* [Update a Role](https://docs.payu.in/docs/update-a-role)
