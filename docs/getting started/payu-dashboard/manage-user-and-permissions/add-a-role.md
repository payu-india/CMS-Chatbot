Roles allow administrators the ability to control what users can do in Dashboard, without giving full administrator access. A role is a collection of permissions based on a job function. Permissions are assigned to roles, and later roles are assigned to users.

To add a role:

1. Navigate to **Dashboard > Settings > User & Permissions**.

   The _User & Permissions_ page is displayed.


<Image src="https://files.readme.io/3b523dc3af49ea0109580fac158eba2d5f1324c462da8faaa26e1a25b4c27c6a-dashboard_manage_roles_employees_list.png" alt="PayU Dashboard - The User & Permissions page is displayed." border={true} />


2. Select the **Roles** tab.

   The **Roles** tab page is displayed.


<Image src="https://files.readme.io/aba0b7b2d3a362e1ee74007389e9a7a58b061fc04a52b6d5054d6eac864b75b8-dashboard_manage_roles_roles_list.png" border={true} />


<br />

2. Click **Add Role** given at the top-right corner of the page.

   The _Add Role_ pop-up page is displayed.


<Image src="https://files.readme.io/5ece56de61293979baf8e4ec8c96a34ef96096fee1bf462bc2a2bb6c4bad93a6-dashboard_add_role.png" alt="PayU Dashboard - The Add Role pop-up page is displayed." border={true} />


3. Enter the role name in the **Role** field.
4. Select the check boxes under the each modules of Dashboard to provide permissions.
5. Click **Create Role** to complete the action.
