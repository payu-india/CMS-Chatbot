To update an existing role on Dashboard:

1. Navigate to **Dashboard > Settings > User & Permissions**.

   The **Manage Employees** tab is displayed on the **Manage Users & Permissions** page.

2. Select the **Manage Roles** tab.

3. Click the **Edit** button (Pencil) on the role entry that you wish to update.

   The *Edit Role Details* pop-up page is displayed.

![PayU Dashboard - The Edit Role Details pop-up page is displayed.](https://devguide.payu.in/wordpress/wp-content/uploads/2021/08/Screenshot-2021-08-18-at-9.55.14-PM-1024x745.jpg)

4. Update the name in the **Role Name** field.
5. Select the check boxes under the various module to grant permissions.
6. Click **Save Changes**.
