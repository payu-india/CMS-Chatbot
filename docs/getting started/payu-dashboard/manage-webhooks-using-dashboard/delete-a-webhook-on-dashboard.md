You can delete an existing webhook URL created on PayU Dashboard as described in this section.

To delete a specific webhook:

1. Select **Developers** > **Webhooks tab**.
2. Click the **Delete** button in the actions field for the webhook .

<Image align="center" alt="PayU Dashboard webhooks - Click the Delete button in the actions field for the webhook" className="border" border={true} src="https://files.readme.io/650e5d65e3fbba54b0be2692ff3b386ae16e6f481cfc93e43613eb99371d7377-dashboard-webhooks-delete-button.png" />

A confirmation message is displayed.

3. Click **Delete** to confirm.
