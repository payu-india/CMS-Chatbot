You can update an existing webhook URL created on PayU Dashboard as described in this section.

> 📘 Only webhook URL can be updated:
> 
> You can update only webhook URL. If you want to change the webhook event, you have to delete that webhook and create a new webhook.

To update a specific webhook:

1. Select **Developers** > **Webhooks tab**.
2. Click the **Edit** button in the actions field for the webhook .
