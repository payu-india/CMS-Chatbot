You can update an existing webhook URL created on PayU Dashboard as described in this section.

> 📘 Only webhook URL can be updated:
>
> You can update only webhook URL. If you want to change the webhook event, you have to delete that webhook and create a new webhook.

To update a specific webhook:

1. Select **Developers** > **Webhooks tab**.
2. Click the **Edit** button in the actions field for the webhook .

<Image align="center" alt="PayU Dashboard webhooks - Click the Edit button in the actions field for the webhook" className="border" border={true} src="https://files.readme.io/920255a1aba0012c15a095966750d726adcfd708dd5300a04012db889a0933ea-dashboard-webhooks-edit-button.png" />

The **Edit Webhook** pop-up page is displayed.

<Image align="center" alt="PayU Dashboard webhooks - The Edit Webhook pop-up page is displayed." className="border" border={true} src="https://files.readme.io/8e71977b47bfdb7dbdfa1d8c431b0ec84e7106a83248b1dbc2528e561d80184c-Screenshot_2024-10-08_at_5.27.51_PM.png" />

3. Update the webhook URL in the **Webhook URL** field.
4. Click **Save** to finish.
