If you forgot your password used to log in PayU Dashboard, you can follow this procedure to reset the password.

To reset the Dashboard Login password:

1. Click the **Forgot Password** option on the Login page.

![PayU Dashboard - Click the Forgot Password option on the Login page](https://devguide.payu.in/wordpress/index.php/wp-json/getobject?keyname=uploads/2022/07/Screenshot-2022-07-11-at-7.48.37-PM-1-1024x629.png)

The *Forgot Password* page is displayed.

![PayU Dashboard - The Forgot Password page is displayed.](https://devguide.payu.in/wordpress/index.php/wp-json/getobject?keyname=uploads/2023/01/Dashboard_Forgot_Password-1024x457.png)

2. Enter your e-mail or mobile number in the Email or Mobile Number field that you used while registering for PayU Dashboard account.
3. Complete the CAPTCHA test (I’m not robot check).
4. Click **Send Reset Link**.

A message similar to the following is displayed below the **Send Reset Link** button.

![PayU Dashboard - A message similar to the following is displayed below the Send Reset Link button.](https://devguide.payu.in/wordpress/index.php/wp-json/getobject?keyname=uploads/2023/01/Dashboard_After_Reset_Msg-852x1024.png)

You will receive a mail similar to the following screenshot:

![PayU Dashboard - ![PayU Dashboard - A message similar to the following is displayed below the Send Reset Link but](https://devguide.payu.in/wordpress/index.php/wp-json/getobject?keyname=uploads/2023/01/Dashboard_Reset_Mail_Sample-1024x808.png)

5. Click **Reset Password** in the mail that you had received from PayU.

The Reset Password page is displayed similar to the following screenshot:

![PayU Dashboard - The Reset Password page is displayed similar to the following screenshot:](https://devguide.payu.in/wordpress/index.php/wp-json/getobject?keyname=uploads/2023/01/Dashboard_Reset_Password-920x1024.png)

6. Enter your new password in the **New Password** and **Confirm Password** fields.

**Note**: If do not enter the new password according to guidelines, a message is displayed with guidelines. Follow the guidelines in the message to enter the new password.

The password confirmation message is displayed. Also, a confirmation SMS is sent to your registered mobile number.

![PayU Dashboard - The password confirmation message is displayed. Also, a confirmation SMS is sent to your registered](https://devguide.payu.in/wordpress/index.php/wp-json/getobject?keyname=uploads/2023/01/Dashboard_Password_Reset_Confirmation.png)
