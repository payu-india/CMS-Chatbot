The filter option enables you to filter the settlement records using the settlement status.

To filter the settlement records:

1. Click **Filter** menu to view the filter options.
2. Select the following check boxes from the **Filter** menu:
   * Settled
   * Processing
   * In Progress
   * On Hold
3. Click **Apply** to get the results.

> 📘 Note:
>
> You can use the **Reset** to clear all checkbox selections.
