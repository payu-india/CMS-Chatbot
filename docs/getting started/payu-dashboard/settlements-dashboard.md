The **Settlement Overview** section displays the vital elements like Date, UTR number, Sales Amount, Fees, Settled Amount, Settlement Status, and the Actions fields by default.

To navigate to the _Settlements Overview_ page:

1. Log in to Merchant Dashboard.
2. Navigate to **Track > Settlements**.

   The _Settlements Overview_ page is displayed.
