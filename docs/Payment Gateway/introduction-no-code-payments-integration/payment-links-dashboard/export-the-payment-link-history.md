To download the payment link records:

1. Click the **Download** drop-down menu to view the options.

<Image align="center" className="border" border={true} src="https://files.readme.io/238e4d7aa7373144cd4799cc70a0bdc1c363df5e428ffa21ce9f67bdbd378ade-dashboard_payment_links_download_reports_drop-down.png" />

2. Select any of the following format to generate the report:

   * csv
   * xlsx
   * Txn - csv
   * Txns - xlsx
   * Old Payment Link Data. - csv
   * Old Payment Link Data - xlsx

A pop-up page is displayed with the status of the report generated.

<Image align="center" src="https://files.readme.io/5c5d55cb7ec1ee700d4f618d9ce8d51dcfb8425dad59a8d27a85fb140cfe5c6b-Screenshot_2025-06-02_at_7.01.35_PM.png" />

3. Click **Download** to complete the action.
