This page helps you **start accepting payments quickly** using the available checkout options.

***

## Get Started Quickly

If your goal is to:

* Accept payments with minimal setup
* Avoid building a payment UI
* Go live quickly

👉 **Hosted Checkout is the recommended starting point**

It provides a ready-to-use payment page and requires the least integration effort.

***

## Other Integration Options

PayU also provides other integration methods such as:

* **Web Checkout** for building a custom payment UI
* **APIs (Server-to-Server)** for fully backend-driven flows

These options offer more flexibility but require additional development effort.

***

## Quick Steps for First Payment

Below are the quick steps to your first successful payment:

1. Set up your PayU test credentials (Merchant Key and Salt)
2. Create a basic payment request from your backend
3. Redirect the user to the PayU hosted payment page
4. Complete a test transaction
5. Receive the payment response on your website

***

## Expected Time

You can complete your **first test payment within minutes** using this approach.

***

## Before You Start

Make sure you:

* Have access to PayU test credentials

***

## Start Your Integration

👉 Go to: **PayU Hosted Checkout → Quick Start**

This will walk you through creating your first working payment with a minimal setup.
