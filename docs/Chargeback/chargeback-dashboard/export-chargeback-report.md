Efficiently manage and export chargeback data using advanced filtering options.

## Export Chargeback report

1. On Merchant Panel, filter the the cases using the fields.
2. Click **Export** to download visible cases.

<Image align="center" className="border" border={true} src="https://files.readme.io/f909e673c1fe58b4ffbffaaa5dc96ffd8a6922f1a55aacb81d24cb56a3d39425-chargeback_dashboard_export_button.png" />

The report is downloaded in Excel (.xlsx) format.

## Download the exported reports

To view the exported chargeback reports:

1. Select **Download Results** from the **Download** menu.

<Image align="center" className="border" border={true} src="https://files.readme.io/095995b03f8c0a99a6eebdd14664a27302ec3cbbdffd217bb8db916aa19034a5-chargeback_dashboard_download_exported_reports.png" />

2. Check the file creation status  in the **Status** column .

Files remain available for 7 days post-creation.

3. Download completed files by clicking the file link in the **File name** column.
