To download the bulk upload report of registration or recurring transactions:

1. Navigate to **Subscriptions** on the PayU Dashboard.
2. Select the **Bulk Upload** tab.
3. Select the **Registration** or **Recurring** sub-tab under the **Bulk Upload** tab.
4. Filter the transactions so the you can list the transaction for which you wish to download the report.
5. Click the **Download** button under the **Action** column for which you wish to download report similar to the following screenshot:

<Image align="center" className="border" border={true} src="https://files.readme.io/a8d72acc3e7e185c23f115d49a85b3a9d62a49c19e83dfb532c68b6ff26c4560-dashboard-suibscriptions-registration-download-report.png" />

A pop-up page is displayed with the progress of the report being generated:

<Image align="center" className="border" width="400px" border={true} src="https://files.readme.io/ff0bea42fcbad8e8043d9ba19cf5f714449d9f1335d717f4e3fc4e805f45089b-dashboard-suibscriptions-registration-report-progress-popup.png" />

The "Report Ready to Download" message is displayed after the report is generated and ready for download similar to the following screenshot:

<Image align="center" className="border" width="400px" border={true} src="https://files.readme.io/41955a005dc17e475bb2da994dae4ea09d8ea8f46655e6cb09989d54679d2d04-dashboard-suibscriptions-registration-report-ready-downloads.png" />

5. Click the **Download and Share** button to download the report.
