To duplicate a subscription payment link:

1. Navigate to the **Subscriptions** on PayU Dashboard.

   The **Links** tab is displayed on the right-pane by default.

2. Click the **Actions** menu and select **Duplicate** for the payment link that wish to deactivate similar to the following screenshot.

<Image align="center" className="border" width="950px" border={true} src="https://files.readme.io/d3a9157db9d164cffc65a397e7d716124eb100c327d01962020367ea1dc56aa3-Screenshot_2024-09-16_at_10.17.23_AM.png" />

The Create Payment Link page is displayed with the details of the payment link selected in Step 2.

<Image align="center" className="border" border={true} src="https://files.readme.io/f5beeb8706198240e1418615b90b9bef157fce69e9f6a7628095c10408034e2c-Dashboard_Subscription_Duplicate_popup-Payment_Link.png" />

3. Update the details as described in the [Create a Subscription Payment Link](doc:create-a-subscription-payment-link-using-dashboard) procedure.
