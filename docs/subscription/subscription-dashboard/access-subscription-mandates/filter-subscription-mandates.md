The filter option enables you to filter the subscription mandates.

To filter the mandates on Subscriptions Dashboard:

1. Navigate to **Subscriptions** on the PayU Dashboard.
2. Select  the **Mandates** tab i(f required).

   The **Mandates** tab of the Subscriptions Dashboard is displayed.

4. Click to select any of the following check box from the **Filter** drop-down menu to filter based on a payment mode.

- Card
- UPI
- ENACH

5. Click **Apply** to get the results.
6. Click the **Date** column header to sort mandates in ascending or descending order based on the creation date. 

> 📘 Reference:
> 
> You can filter the subscription mandates by last week, month or by custom date range similar to Transactions Dashboard. For more information, refer to [View Transactions for a Custom Period](doc:view-transactions-for-a-custom-period).

> 📘 Note:
> 
> You can use the **Reset** to clear all checkbox selections.
