To create a new payment link:

1. Click **Create New Payment** at the top right corner of the page.

   The _Create New Payment Link_ pop-up page is displayed to add the details like amount and purpose of payment.

[block:image]{"images":[{"image":["https://files.readme.io/9978e13-Screenshot_2023-09-29_at_12.03.29_PM.png",null,null],"align":"center"}]}[/block]

2. Enter the amount to be paid in the **Amount** field.
3. Enter a description on the payment purpose in the **Purpose of Payment** field.
4. Select the **Collect Partial Payment** check box to enable the partial payment collection.
5. Click **Add more details**.

   A pop-up page with additional parameters is displayed.

[block:image]{"images":[{"image":["https://files.readme.io/86646ab-Screenshot_2023-09-29_at_12.04.22_PM.png",null,null],"align":"center"}]}[/block]

6. Select the check box against the parameters you wish to select and click **Add details** to save the changes.
7. Click **CreatePayment Link** to complete the action.
