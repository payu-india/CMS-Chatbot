You can add a rule involving single or multiple payment methods with Priority-Based Routing. This section describes how to add a routing rule with examples.

## Add a rule for Net Banking

1. Select the **Routing Rules** tab on the Maximizer Dashboard.

5. Enter the amount range in the **Transaction Amount Range** field. For more information, refer to [Include an Amount Range with a Routing Rule](doc:include-an-amt-range-with-routing-rule).

6. Click **Next** after you have selected the banks for Net Banking routing.

The _Payment Aggregator_ screen is displayed.

9. Select the **Set Custom Baseline** check box to configure custom baseline for this rule/

> 
> For detailed understanding on baseline, refer to [Understanding Baseline Logic](doc:understanding-baseline-logic).

10. Click **Next**.

The_ Rule Guidelines_ screen is displayed.

12. Click **Publish Now** to create the rule.

   The rule is added to the **Routing Rules **tab of Maximizer dashboard.
