You can mark a routing rule inactive if you do not want use that routing rule. Inactive rules will not be applied at the during routing.

> 📘 Note:
> 
> Currently, you cannot revert or make an inactive rule to the active state.

To mark a routing rule inactive:

1. Select the **Routing Rules** tab on the Maximizer Dashboard.

   The **Routing Rules** tab is displayed with existing rules.
