You can mark a routing rule inactive if you do not want use that routing rule. Inactive rules will not be applied at the during routing.

> 📘 Note:
>
> Currently, you cannot revert or make an inactive rule to the active state.

To mark a routing rule inactive:

1. Select the **Routing Rules** tab on the Maximizer Dashboard.

   The **Routing Rules** tab is displayed with existing rules.

<Image align="center" className="border" border={true} src="https://files.readme.io/9ab0ce4-Screenshot_2024-06-20_at_9.56.39_AM.png" />

<Image align="center" width="00px" src="https://files.readme.io/3e1f65b-Screenshot_2024-06-19_at_10.18.01_AM.png" />

2. Click the hamburger menu under Actions and select **Mark Inactive**.

   The rule is marked inactive and displays Inactive in the **Status** column.
