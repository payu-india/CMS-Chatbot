To modify an existing routing rule:

1. Select the **Routing Rules** tab on the Maximizer Dashboard.

   The **Routing Rules** tab is displayed with existing rules.

2. Click the hamburger menu under Actions and select **Update**.

The _Manage Rule_ page with the _Rule Configuration_ screen is displayed. In this example, the Net Banking payment method is configured.

3. Udate the payment types and click **Next**.

   The _Payment Aggregator_ screen is displayed.
4. Select **Success Based Routing** tab (if required).
5. Remove the payment aggregators using the remove button (**X**) and then click **Next**.

   The_ Rule Guidelines_ screen is displayed.

6. Enter the name for the rule in the **Title** field.
7. Click **Create Rule** to create the rule.

   The rule is added to the **Routing Rules **tab of Maximizer dashboard.
