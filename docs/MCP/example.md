Use natural language to interact with PayU services through the Remote MCP. This page provides examples of common operations you can perform.

## Transaction Management

### View Transaction History

```
"Show me transactions for the last 7 days"
```

```
"List all transactions from January 1st to January 15th"
```

```
"Show me failed transactions from this week"
```

### Get Transaction Details

```
"Get details for transaction TX-98765"
```

```
"What is the status of transaction ID 12345678?"
```

```
"Show me the complete information for order ORD-2026-001"
```

<br />

## Payment Operations

### Process Refunds

```
"Process a refund for transaction TX-12345"
```

```
"Refund the full amount for order ORD-2026-001"
```

### Check Payment Status

```
"Check the status of payment PAY-12345"
```

```
"What is the current status of transaction TX-98765?"
```

```
"Is payment for order ORD-2026-001 completed?"
```

### View Settlement Information

```
"Check the status of settlement S-567890"
```

```
"Show me today's settlement details"
```

```
"When will the pending settlements be processed?"
```

### List Pending Payouts

```
"List all pending payouts"
```

```
"Show me payouts scheduled for this week"
```

```
"What payouts are awaiting processing?"
```
