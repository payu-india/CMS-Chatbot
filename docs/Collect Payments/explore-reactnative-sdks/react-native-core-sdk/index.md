Integrate with the PayU React Native Core SDK to start collecting payments from you app build using React Native framework. The React Native Core SDK works as a wrapper around PayU core SDK that allows allows you to integrate with the PayU PG with minimal integration effort and accept payments faster. To integrate PayU React Native Core SDK, see Integrate Core SDK with React Native App.

## Compatibility

### Android

* Minimum SDK Version: 21
* Compile SDK Version: 31+
* Kotlin 1.6.10

### iOS

* Minimum iOS Version: 11

The procedure to integrate with Core SDK slightly varies for Android and iOS integration. The following sections describe the procedure to integrate Core SDK with Android and iOS:

* Integrate React Native Core with Android
* Integrate React Native Core with iOS
