The PayUCheckoutPro experience allows you to integrate with the PayU PG with minimal integration effort and accept payments faster.

## Features

The PayUCheckoutPro SDK gives you the following key capabilities:

* A complete, ready-to-use native Checkout UI
* Support for multiple payment options:
* All major Credit/Debit card providers (Amex, Mastercard, Rupay, Visa, and more)
* Netbanking with 150+ Indian banks
* UPI Payments (Intent & Collect)
* Google Pay™ InApp & Cards
* PhonePe InApp & Intent
* Native OTP Assist
* Recurring Payments
* Convenience Fee support
* Offers support
* LazyPay Support
* Multi-Currency Payments Support
* Prepaid Wallets
* CC & DC EMI Payments
* OTP read for faster and improved OTP authentication
* Enforce Payment Mode
* Customization capabilities to make the SDK your own

This plugin guides you through the step-by-step instructions and integration code inside your IDE which helps in integrating any PayU SDK in less than an hour.

One of the benefits of using PayU's Integration Helper is that it is automatically updated with the latest features and security patches, as we do it for you over the air.

## How to Install PayCheckoutPro SDK plugin

* Open IntelliJ IDEA or Android Studio.
* Navigate to Settings (IntelliJ IDEA) or Preferences (Android Studio).
* Select Plugins from the left sidebar.
* Click on the Marketplace tab.
* Search for "PayU-Integration-Plugin" in the search box.
* Click Install and then Restart IDE to apply the changes.
