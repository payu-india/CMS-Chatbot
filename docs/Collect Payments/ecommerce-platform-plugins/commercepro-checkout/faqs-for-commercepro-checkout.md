This page answers frequently asked questions about PayU CommercePro Checkout, including supported platforms, benefits, and the customer journey.

<Callout icon="📘" theme="info">
  **Reference**: For an overview, refer to [CommercePro Checkout](doc:commercepro-checkout).
</Callout>

<Accordion title="1. What is CommercePro Checkout?" icon="fa-info-circle">
  PayU's CommercePro Checkout provides a comprehensive checkout solution for merchants. It helps minimize RTO by limiting COD based on a customer's likelihood to create an RTO on a transaction. It also allows customers to securely save payment details and addresses for use across PayU network merchants.
</Accordion>

<Accordion title="2. Which platforms support CommercePro Checkout?" icon="fa-info-circle">
  PayU supports CommercePro on **WooCommerce** and **Magento**. For installation and configuration, refer to [CommercePro Checkout for WooCommerce](doc:commercepro-platform-for-woocommerce) and [CommercePro Checkout for Magento](doc:commercepro-platform-for-magento).
</Accordion>

<Accordion title="3. What are the key benefits of CommercePro Checkout?" icon="fa-info-circle">
  CommercePro Checkout offers two-step OTP login with pre-filled customer information, address pre-fill from PayU's address vault, COD via PayU PG, a recommendation engine for payment options, built-in RTO intelligence (PIN code, address, and mobile blacklisting, plus COD amount limits), refunds from WooCommerce and Magento dashboards, and in-built support for the PayU offers engine with reconciliation.
</Accordion>

<Accordion title="4. What is the customer journey with CommercePro Checkout?" icon="fa-info-circle">
  After products are added to the cart, **PayU Checkout Express** is available at checkout. Customers complete OTP login, review pre-filled address details (and can update or add addresses), then proceed to the PayU Checkout page where applicable offers are shown and payment modes are ordered dynamically. For screenshots and step details, refer to [CommercePro Checkout](doc:commercepro-checkout).
</Accordion>

<Accordion title="5. How does CommercePro help reduce RTO?" icon="fa-info-circle">
  CommercePro includes built-in RTO intelligence that supports COD blacklisting based on PIN codes, addresses, and mobile numbers, and lets merchants set a maximum amount limit for COD orders.
</Accordion>
