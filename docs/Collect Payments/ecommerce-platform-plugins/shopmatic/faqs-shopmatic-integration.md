<Accordion title="1. Which payment methods does PayU support on Shopmatic?" icon="fa-info-circle">
  PayU on Shopmatic supports cards (VISA, MasterCard, Diners, American Express), Net Banking, UPI, EMI, and wallets. Availability may depend on your merchant account configuration.
</Accordion>

<Accordion title="2. How does checkout work with PayU on Shopmatic?" icon="fa-info-circle">
  At checkout, customers are redirected to PayU to complete payment securely. After a successful payment, the order is confirmed and the customer is redirected back to your Shopmatic web-store.
</Accordion>

<Accordion title="3. What do I need before enabling PayU on Shopmatic?" icon="fa-info-circle">
  You need a Shopmatic account and your PayU Merchant Key and Salt. Register for a PayU merchant account before starting integration. For more information, refer to [Register for a Merchant Account](doc:register-for-a-merchant-account-on-dashboard).
</Accordion>

<Accordion title="4. Where can I find setup and troubleshooting help for Shopmatic?" icon="fa-info-circle">
  For enablement steps, refer to [Enable PayU for Shopmatic](doc:enable-payu-for-shopmatic). If the plugin is not working, verify your API key and Salt configuration and refer to [Troubleshooting Shopmatic Integration](doc:troubleshooting-shopmatic-integration).
</Accordion>

<Accordion title="5. The PayU Plugin that I installed is not working?" icon="fa-info-circle">
Check whether the merchant API key and Salt are configured accurately and navigate to [Merchant Dashboard](http://onboarding.payu.in/) and verify these values. For more information, refer to Step 5 or [Enable PayU for Shopmatic](doc:enable-payu-for-shopmatic).For more information on generating API key and salt, refer to [Generate Test Merchant Key and Salt](doc:generate-test-merchant-key-and-salt).
</Accordion>
