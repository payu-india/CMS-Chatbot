This section includes answers for frequently asked questions about integrating PayU with Zoho products, including Zoho One, Commerce, Billing, and Inventory.

<Callout icon="📘" theme="info">
  **Reference**: For an overview, refer to [Zoho](doc:zoho-integration).
</Callout>

## General

<Accordion title="Which Zoho products support PayU?" icon="fa-info-circle">
  PayU payment gateway can be set up for Zoho One, Zoho Commerce, Zoho Invoice, Zoho Billing, and Zoho Inventory.
</Accordion>

<Accordion title="How do I integrate PayU with Zoho One?" icon="fa-info-circle">
  Install the PayU app on Zoho Marketplace and configure the PayU plugin for Zoho One. Invoicing is done using Zoho Invoice. For more information, refer to [Install PayU app on Zoho Marketplace](doc:install-payu-app-on-zoho-marketplace) and [Configure PayU Plugin for Zoho One](doc:configure-payu-plugin-for-zoho-one).
</Accordion>

<Accordion title="How do I set up PayU on Zoho Commerce?" icon="fa-info-circle">
  Set up PayU as your payment gateway on Zoho Commerce to collect payments from your customers when they place orders on your online store.
</Accordion>

<Accordion title="How do I enable PayU for Zoho Billing?" icon="fa-info-circle">
  To enable the PayU payment gateway for Zoho Billing, refer to [Enable PayU for Zoho Billing](doc:enable-payu-for-zoho-billing).
</Accordion>

<Accordion title="How do I enable PayU for Zoho Inventory?" icon="fa-info-circle">
  Install the PayU app on Zoho Marketplace and enable PayU for Zoho Inventory. For more information, refer to [Install PayU app on Zoho Marketplace](doc:install-payu-app-on-zoho-marketplace) and [Enable PayU for Zoho Inventory](doc:enable-payu-for-zoho-inventory).
</Accordion>
