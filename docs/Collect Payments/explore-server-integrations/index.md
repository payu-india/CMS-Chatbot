By using PayU Payment Gateway, you can integrate your server using the below listed languages:

1. [Go](https://docs.payu.in/docs/go-sdk)
2. [Java](https://docs.payu.in/docs/java-sdk)
3. [PHP](https://docs.payu.in/docs/php-sdk)
4. [Python](https://docs.payu.in/docs/python-sdk)
5. [Node.js](https://docs.payu.in/docs/node-js-sdk)

After successful integration, you can accept payments using any of the [Payment Methods](https://docs.payu.in/docs/configure-user-settings#checkout-payment-modes) we support.

The [UPI Smart Intent - Non SDK Flow](doc:upi-smart-intent-non-sdk-flow) outlines the process for integrating UPI (Unified Payments Interface) payment functionality into a mobile app or website without using an SDK. This integration allows you to facilitate payments using UPI apps installed on the user's device, streamlining the payment process and enhancing user experience by reducing app-switching.
