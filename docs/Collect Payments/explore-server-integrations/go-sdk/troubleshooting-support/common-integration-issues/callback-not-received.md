## Overview

Callback or webhook not received.

- [ ] URL is HTTPS
- [ ] URL publicly accessible: `curl -I https://yoursite.com/webhook`
- [ ] Returns 200 or 405 (not 404/500)
- [ ] Webhook enabled in Dashboard
