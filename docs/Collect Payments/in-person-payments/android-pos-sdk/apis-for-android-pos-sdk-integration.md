The following APIs used to integrate Android POS SDK:

* [Get Device Information API](https://docs.payu.in/reference/get-device-information-api)
* [Update App API](https://docs.payu.in/reference/update-app-api)
* [Initiate Transaction API](https://docs.payu.in/reference/initiate-transaction-api)
* [Get Bank List API](https://docs.payu.in/reference/get-bank-list-api)
* [EMI Tenure List API](https://docs.payu.in/reference/emi-tenure-list-api)
* [EMI Transaction API](https://docs.payu.in/reference/emi-transaction-api)
* [Signature Capture API](https://docs.payu.in/reference/signature-capture-api)
* [Transaction Details API](https://docs.payu.in/reference/transaction-details-api)
* [Initiate Void Transaction API](https://docs.payu.in/reference/initiate-void-transaction-api)
* [Send SMS and Email API](https://docs.payu.in/reference/send-sms-and-email-api)
* [Print Receipts API](https://docs.payu.in/reference/print-receipts-api)

For the shared response payload, refer to [Shared Response Payload](#hared-response-payload).
