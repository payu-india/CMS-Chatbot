<PaymentAPIEnvironment />

<Tabs>
  <Tab title="Request Parameters">

**Mandatory Parameters**

<table>
<thead><tr><th>Parameter</th><th>Description</th></tr></thead>
<tbody>
<tr><td>key</td><td><code>String</code> Merchant key provided by PayU during onboarding.</td></tr>
<tr><td>txnid</td><td><code>String</code> The transaction ID is a reference number generated by the merchant.</td></tr>
<tr><td>amount</td><td><code>String</code> The payment amount for the transaction.</td></tr>
<tr><td>productinfo</td><td><code>String</code> A brief description of the product.</td></tr>
<tr><td>firstname</td><td><code>String</code> The first name of the customer.</td></tr>
<tr><td>email</td><td><code>String</code> The email address of the customer.</td></tr>
<tr><td>phone</td><td><code>String</code> The phone number of the customer.</td></tr>
<tr><td>pg</td><td><code>String</code> For cards, CC will be the value.</td></tr>
<tr><td>bankcode</td><td><code>String</code> Each payment option is identified with a unique bank code at PayU.</td></tr>
<tr><td>ccnum</td><td><code>String</code> Use 13-19 digit card number and validate with LUHN algorithm.</td></tr>
<tr><td>ccname</td><td><code>String</code> The name on card as entered by the customer.</td></tr>
<tr><td>ccvv</td><td><code>String</code> Use 3-digit CVV number. Validate with BIN API.</td></tr>
<tr><td>ccexpmon</td><td><code>String</code> Card expiry month in MM format.</td></tr>
<tr><td>ccexpyr</td><td><code>String</code> Card expiry year in four digits.</td></tr>
<tr><td>furl</td><td><code>String</code> The failure URL for failed transactions.</td></tr>
<tr><td>surl</td><td><code>String</code> The success URL for successful transactions.</td></tr>
<tr><td>hash</td><td><code>String</code> SHA-512(key|txnid|amount|productinfo|firstname|email|udf1|udf2|udf3|udf4|udf5||||||Salt)</td></tr>
<tr><td>txn_s2s_flow</td><td><code>String</code> Must be passed with value 4 for Legacy Decoupled flow.</td></tr>
<tr><td>auth_only</td><td><code>String</code> Must be passed with value 2 for authentication-only flow.</td></tr>
<tr><td><Glossary>authentication_flow</Glossary></td><td><code>String</code> Authentication flow type. Use "decoupled" for decoupled flow.</td></tr>
</tbody></table>

**Optional Parameters**

<table>
<thead><tr><th>Parameter</th><th>Description</th></tr></thead>
<tbody>
<tr><td>address1</td><td><code>String</code> The first line of the billing address. For Fraud Detection: helpful for fraud detection and chargebacks.</td></tr>
<tr><td>address2</td><td><code>String</code> The second line of the billing address.</td></tr>
<tr><td>city</td><td><code>String</code> The city where the customer resides.</td></tr>
<tr><td>state</td><td><code>String</code> The state where the customer resides.</td></tr>
<tr><td>country</td><td><code>String</code> The country where the customer resides.</td></tr>
<tr><td>zipcode</td><td><code>String</code> Billing address zip code. Mandatory for cardless EMI. Character Limit: 20.</td></tr>
<tr><td>udf1-udf5</td><td><code>String</code> User-defined fields for storing transaction-specific data.</td></tr>
</tbody></table>

  <Tab title="Sample Request">

```curl
curl --location 'https://test.payu.in/_payment' \
--header 'Content-Type: application/x-www-form-urlencoded' \
--data-urlencode 'key=YOUR_MERCHANT_KEY' \
--data-urlencode 'txnid=TXN_12345' \
--data-urlencode 'amount=10.00' \
--data-urlencode 'productinfo=iPhone' \
--data-urlencode 'firstname=Ashish' \
--data-urlencode 'email=test@gmail.com' \
--data-urlencode 'phone=9876543210' \
--data-urlencode 'pg=CC' \
--data-urlencode 'bankcode=VISA' \
--data-urlencode 'ccnum=5123456789012346' \
--data-urlencode 'ccname=Ashish Kumar' \
--data-urlencode 'ccvv=123' \
--data-urlencode 'ccexpmon=10' \
--data-urlencode 'ccexpyr=2025' \
--data-urlencode 'surl=https://apiplayground-response.herokuapp.com/' \
--data-urlencode 'furl=https://apiplayground-response.herokuapp.com/' \
--data-urlencode 'txn_s2s_flow=4' \
--data-urlencode 'auth_only=2' \
--data-urlencode 'authentication_flow=decoupled' \
--data-urlencode 'hash=YOUR_HASH_VALUE'
```
```python
import requests
url="https://test.payu.in/_payment"
data={"key":"YOUR_MERCHANT_KEY","txnid":"TXN_12345","amount":"10.00","productinfo":"iPhone",
    "firstname":"Ashish","email":"test@gmail.com","phone":"9876543210","pg":"CC","bankcode":"VISA",
    "ccnum":"5123456789012346","ccname":"Ashish Kumar","ccvv":"123","ccexpmon":"10","ccexpyr":"2025",
    "surl":"https://apiplayground-response.herokuapp.com/",
    "furl":"https://apiplayground-response.herokuapp.com/",
    "txn_s2s_flow":"4","auth_only":"2","authentication_flow":"decoupled","hash":"YOUR_HASH_VALUE"}
r=requests.post(url,headers={"Content-Type":"application/x-www-form-urlencoded"},data=data)
print(r.status_code); print(r.text)
```
