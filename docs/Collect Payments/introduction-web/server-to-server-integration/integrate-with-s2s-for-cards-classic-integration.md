**Mandatory Parameters**

<table>
<thead><tr><th>Parameter</th><th>Description</th></tr></thead>
<tbody>
<tr><td>key</td><td><code>String</code> Merchant key provided by PayU during onboarding.</td></tr>
<tr><td>txnid</td><td><code>String</code> The transaction ID is a reference number generated by the merchant.</td></tr>
<tr><td>amount</td><td><code>String</code> The payment amount for the transaction.</td></tr>
<tr><td>productinfo</td><td><code>String</code> A brief description of the product.</td></tr>
<tr><td>firstname</td><td><code>String</code> The first name of the customer.</td></tr>
<tr><td>email</td><td><code>String</code> The email address of the customer.</td></tr>
<tr><td>phone</td><td><code>String</code> The phone number of the customer.</td></tr>
<tr><td>pg</td><td><code>String</code> For cards, CC will be the value.</td></tr>
<tr><td>bankcode</td><td><code>String</code> Each payment option is identified with a unique bank code at PayU.</td></tr>
<tr><td>ccnum</td><td><code>String</code> Use 13-19 digit card number and validate with LUHN algorithm.</td></tr>
<tr><td>ccname</td><td><code>String</code> The name on card as entered by the customer.</td></tr>
<tr><td>ccvv</td><td><code>String</code> Use 3-digit <Glossary>CVV</Glossary> number. Validate with <Glossary>BIN</Glossary> API.</td></tr>
<tr><td>ccexpmon</td><td><code>String</code> Card expiry month in MM format.</td></tr>
<tr><td>ccexpyr</td><td><code>String</code> Card expiry year in four digits.</td></tr>
<tr><td>furl</td><td><code>String</code> The failure URL for failed transactions.</td></tr>
<tr><td>surl</td><td><code>String</code> The success URL for successful transactions.</td></tr>
<tr><td>hash</td><td><code>String</code> SHA-512(key|txnid|amount|productinfo|firstname|email|udf1|udf2|udf3|udf4|udf5||||||Salt)</td></tr>
</tbody></table>

**Optional Parameters**

<table>
<thead><tr><th>Parameter</th><th>Description</th></tr></thead>
<tbody>
<tr><td>address1</td><td><code>String</code> The first line of the billing address. For <Glossary>Fraud Detection</Glossary>: helpful for fraud detection and chargebacks.</td></tr>
<tr><td>address2</td><td><code>String</code> The second line of the billing address.</td></tr>
<tr><td>city</td><td><code>String</code> The city where the customer resides.</td></tr>
<tr><td>state</td><td><code>String</code> The state where the customer resides.</td></tr>
<tr><td>country</td><td><code>String</code> The country where the customer resides.</td></tr>
<tr><td>zipcode</td><td><code>String</code> Billing address zip code. Mandatory for cardless EMI. Character Limit: 20.</td></tr>
<tr><td>udf1-udf5</td><td><code>String</code> User-defined fields for storing transaction-specific data.</td></tr>
</tbody></table>

```java
import java.net.*; import java.net.http.*; import java.nio.charset.*; import java.util.*;
public class ClassicS2S { public static void main(String[] a) throws Exception {
var p=new LinkedHashMap<String,String>(); p.put("key","YOUR_MERCHANT_KEY"); p.put("txnid","TXN_12345");
p.put("amount","10.00"); p.put("productinfo","iPhone"); p.put("firstname","Ashish");
p.put("email","test@gmail.com"); p.put("phone","9876543210"); p.put("pg","CC"); p.put("bankcode","VISA");
p.put("ccnum","5123456789012346"); p.put("ccname","Ashish Kumar"); p.put("ccvv","123");
p.put("ccexpmon","10"); p.put("ccexpyr","2025");
p.put("surl","https://apiplayground-response.herokuapp.com/");
p.put("furl","https://apiplayground-response.herokuapp.com/"); p.put("hash","YOUR_HASH_VALUE");
var sj=new StringJoiner("&"); for(var e:p.entrySet()) sj.add(URLEncoder.encode(e.getKey(),StandardCharsets.UTF_8)+"="+URLEncoder.encode(e.getValue(),StandardCharsets.UTF_8));
var resp=HttpClient.newHttpClient().send(HttpRequest.newBuilder().uri(URI.create("https://test.payu.in/_payment"))
.header("Content-Type","application/x-www-form-urlencoded").POST(HttpRequest.BodyPublishers.ofString(sj.toString())).build(),HttpResponse.BodyHandlers.ofString());
System.out.println("Status: "+resp.statusCode()); System.out.println(resp.body()); }}
```
