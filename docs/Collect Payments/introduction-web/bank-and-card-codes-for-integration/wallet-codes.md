In the Merchant Hosted Checkout integration, you must use **CASH** with the **pg** parameter  for collecting payment using wallets. The following table provides the codes for the leading wallets in India. This code must be used as a value with the **<Glossary>bankcode</Glossary>** parameter.

> 📘 For Advantage Club wallet integration:
>
> For Advantage Club wallet integration, use the following:
>
> - `pg=RD `&#x20;
> - `bankcode=ADVCLUB`

| **Wallet**                                                  | **bankcode** |
| ----------------------------------------------------------- | ------------ |
| Amazon Pay                                                  | AMZPAY       |
| Airtel Money                                                | AMON         |
| Ola Money                                                   | OLAM         |
| ItzCash                                                     | ITZC         |
| HDFC PayZapp                                                | PAYZP        |
| MobiKwik                                                    | MOBIKWIK     |
| PhonePe                                                     | PHONEPE      |
| Advantage Club<br />**Note**: Must be used with **pg = RD** | ADVCLUB      |
