* [Payment Mode Codes](doc:payment-mode-codes): Codes to be used for each payment mode that must be used in various API integrations with PayU. In [Custom Checkout  (Merchant Hosted) integration](doc:custom-checkout-merchant-hosted), these codes must be used with the **pg** parameter.
* [Net Banking Codes](doc:net-banking-codes): Codes to be used with the **bankcode** parameter for [Collect Payments with NetBanking](/docs/collect-payments-with-net-banking-seamless).
* [Card Type Codes and Supported Banks for Cards](doc:card-type-codes-and-supported-banks-for-cards) : Codes to be used with the **bankcode** parameter for [Collect Payments with Cards](doc:collect-payments-with-cards-seamless).
* [Card Number Formats](doc:card-number-formats): List of valid card numbers for each card type and algorithm to validate card numbers.
* [Wallet Codes](doc:wallet-codes): Codes to be used with the **bankcode** parameter for [Collect with Wallets](/docs/collect-payments-with-wallets-seamless).
* [UPI Handles](doc:upi-handles): UPI handles are to be used with the **VPA** parameter for [Collect Payments with UPI](doc:collect-payments-with-upi-seamless)
* [EMI Codes](doc:emi-codes): EMI codes are to be used with the **bankcode** parameter for [Integrate with Credit Card using Merchant Hosted Checkout - EMI](doc:collect-payments-with-emi-using-credit-card).
* [BNPL Codes](doc:bnpl-codes): Codes to be used with the **bankcode** parameter for [Collect Payments with BNPL](doc:collect-payments-with-bnpl).
