## PayU Plugin is not working

Check whether the merchant API key and Salt are configured accurately and navigate to [Merchant Dashboard](http://onboarding.payu.in/) and verify these values. For more information, refer to Step 5 or [Enable PayU for Shopmatic](doc:enable-payu-for-shopmatic).For more information on generating API key and salt, refer to [Generate Test Merchant Key and Salt](doc:generate-test-merchant-key-and-salt).
