You can filter subscription payment links on Subscriptions Dashboard for a date range and/or payment link status.

To filter the subscription payment links on Subscriptions Dashboard:

1. Navigate to **Subscriptions** on the PayU Dashboard.
2. Select the **Links** tab.
3. Click the **Filter** drop-down menu to list the filter options similar to the following screenshot.

<Image align="center" className="border" border={true} src="https://files.readme.io/b5153461d6887913cc7abfc1f329f31e8adc26de6d335aa68fc53002e8ecf12e-Screenshot_2024-09-16_at_10.21.32_AM.png" />

4. Click to select any of the following check box from the **Filter** drop-down menu.

* Active
* Dashboard
* Expired

5. Click **Apply** to get the results.

> 📘 Reference:
>
> You can filter the subscription payment links by last week, month or by custom date range similar to Transactions Dashboard. For more information, refer to [View Transactions for a Custom Period](doc:view-transactions-for-a-custom-period).

> 📘 Note:
>
> You can use the **Reset** to clear all checkbox selections.
