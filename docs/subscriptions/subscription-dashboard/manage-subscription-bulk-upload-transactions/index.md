<Callout icon="📘" theme="info">

  * Export the bulk upload transactions in the CSV or XSLX format. For more information, refer to [Export the Transaction Records](doc:export-the-transaction-records).
  * You can filter the bulk upload transactions by last week, month or by custom date range.  For more information, refer to [View Transactions for a Custom Period](doc:view-transactions-for-a-custom-period).
  * Search the bulk upload transactions based on Batch ID or Description. For more information, refer to [Search the Transactions](doc:search-the-transactions).
</Callout>

## Filter the Uploaded Transactions

The filter option enables you to filter the transactions by processing status.

To filter the bulk upload transactions on Subscriptions Dashboard:

1. Navigate to **Subscriptions** on the PayU Dashboard.
2. Select the **Registration** or **Recurring** sub-tab under the **Bulk Upload** tab.
3. Click the **Filter** drop-down menu to list the filter options.

> **Note**: The filter options vary for **Registration** and **Recurring** sub-tabs.

<Image align="center" border={true} src="https://files.readme.io/8eac6a4f41d33e35d3569f924bffd819c71406b011b7ea152dc9937f4b0713d9-Screenshot_2024-09-16_at_11.23.10_AM.png" className="border" />

4. Click to select any of the following check box from the **Filter** drop-down menu for the **Registration** sub-tab.

* Processed
* Processing
* Partial Processing

For the **Recurring** sub-tab, the following options are displayed:

* Processed
* Processing

5. Click **Apply** to get the results.

<Callout icon="📘" theme="info">
  **Reference**: You can filter the bulk upload transactions by last week, month or by custom date range similar to Transactions Dashboard. For more information, refer to [View Transactions for a Custom Period](doc:view-transactions-for-a-custom-period).
</Callout>

<Callout icon="📘" theme="info">
  **Note**: You can use the **Reset** to clear all checkbox selections.
</Callout>

## Download the Uploaded Transactions Report

To download the bulk upload report of registration or recurring transactions:

1. Navigate to **Subscriptions** on the PayU Dashboard.
2. Select the **Bulk Upload** tab.
3. Select the **Registration** or **Recurring** sub-tab under the **Bulk Upload** tab.
4. Filter the transactions so the you can list the transaction for which you wish to download the report.
5. Click the **Download** button under the **Action** column for which you wish to download report similar to the following screenshot:

<Image align="center" border={true} src="https://files.readme.io/a8d72acc3e7e185c23f115d49a85b3a9d62a49c19e83dfb532c68b6ff26c4560-dashboard-suibscriptions-registration-download-report.png" className="border" />

A pop-up page is displayed with the progress of the report being generated:

<Image align="center" border={true} width="400px" src="https://files.readme.io/ff0bea42fcbad8e8043d9ba19cf5f714449d9f1335d717f4e3fc4e805f45089b-dashboard-suibscriptions-registration-report-progress-popup.png" className="border" />

The "Report Ready to Download" message is displayed after the report is generated and ready for download similar to the following screenshot:

<Image align="center" border={true} width="400px" src="https://files.readme.io/41955a005dc17e475bb2da994dae4ea09d8ea8f46655e6cb09989d54679d2d04-dashboard-suibscriptions-registration-report-ready-downloads.png" className="border" />

5. Click the **Download and Share** button to download the report.

## Deactivate a Uploaded Payment Link

To deactivate a registration transactions done through bulk upload:

1. Navigate to **Subscriptions** on the PayU Dashboard.
2. Select the **Bulk Upload** tab.
3. Select the **Registration** sub-tab under the **Bulk Upload** tab.
4. Filter the transactions so the you can list the transaction for which you wish to deactivate.
5. Click the **Deactivate** button under the **Action** column for which you wish to download report similar to the following screenshot:

<Image align="center" border={true} src="https://files.readme.io/3598c0e5ad693862791efb7cbbae17085e2191ab2a1930d6d9ea58e6dc6fea4f-dashboard-suibscriptions-deactivate-registration-transaction.png" className="border" />

A pop-up page is displayed for confirmation:

<Image align="center" border={true} width="400px" src="https://files.readme.io/ba5c50a92667b268d5c9e958571c26cc1736776b47427bed91a3504721947be7-dashboard-suibscriptions-deactivate-confirmation.png" className="border" />

5. Click the **Yes, Deactivate** button to deactivate the transactions you had selected.
