PayU allows applying of multiple offers to support merchants who often run co-funded offers with their own offers. The different combinations in which the offers can be applied are:

- No-Cost EMI and Instant Discount
- No-Cost EMI and Cash Back
- Low-Cost EMI and Instant Discount
- Low-Cost EMI and Cash Back

## **Base Offer**

To support the application of multiple offers, PayU has introduced a new offer type known as **Base Offer**. A Base Offer has the following properties:

- A Base Offer can be applied with any Instant Discount or Cash Back offers
- A Base offer can only be No-Cost EMI or Low-Cost EMI
- On the PayU Payment page with PayU Hosted Checkout integration, the Base Offer will be applied automatically without the need for user to select them. If the offer is applicable, it will be applied

## **Creating a Base Offer**

The procedure to create a Base Offer involves the following:

1. Navigate to [_Offers_ section of PayU Dashboard](https://devguide.payu.in/affordability/getting-started-with-affordability/navigate-to-offer-engine/).
2. Click **Create an Offer** at the top-right corner.

The _Create New Offer_ page is displayed.

![](https://devguide.payu.in/wordpress/index.php/wp-json/getobject?keyname=uploads/2023/03/Screenshot-2023-03-23-at-11.15.54-AM-1024x662.png)

1. Select the discount type as **Base Offer**

 The _Choose a base offer type_ page is displayed.

![](https://devguide.payu.in/wordpress/index.php/wp-json/getobject?keyname=uploads/2023/03/Screenshot-2023-03-24-at-11.13.07-AM-1024x611.png)

1. Select any of the following Base offer types:
   - No Cost EMI
   - Low Cost EMI
2. Based on your selection in Step 4, refer to any of the following sections and complete creating the Base Offer:
   - No Cost EMI
   - Low Cost EMI
