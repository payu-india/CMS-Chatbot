When your customer wants to opt for the Cardless EMI option, you can use the EMI APIs to check the customer’s eligibility and get the EMI amount, interest, processing fee, or No-Cost EMI and tenure. If the customer is eligible, you can post the Cardless EMI transaction. This section describes the procedure to integrate Cardless EMI with S2S integration.

## Step 1: Check the cardless EMI eligibility

After collecting the customer’s card information and the amount to be paid, use the **Eligible BINs for EMI API v2.0** API to check the eligibility. For more information, refer to [Eligible BINs for EMI API v2.0](ref:eligible-bins-for-emi-v20).

## Step 2: Initiate the payment

Post the following additional parameters for using the Cardless EMI. Check the response when you try enter the values in API Reference. For complete list of parameters, refer to [Collect Payment API - EMI](ref:_payment_merchant_hosted_emi) for the complete list parameters with **Try It** experience.

### Sample request

```curl
curl --location 'https://test.payu.in/_payment' \
--header 'Cookie: PHPSESSID=b8264eu32nu8bf756rpf7onmph; USERTXNINFO=66e7e98a452e89.37972937; PHPSESSID=676e9b6bdcf25' \
--form 'key="evEiGQ"' \
--form 'txnid="240d17j1ddj5dA195d4dd28f"' \
--form 'amount="10000"' \
--form 'firstname="test"' \
--form 'email="test@test.in"' \
--form 'phone="9999999999"' \
--form 'productinfo="test"' \
--form 'surl="https://apiplayground-response.herokuapp.com/"' \
--form 'furl="https://apiplayground-response.herokuapp.com/"' \
--form 'hash="<hash>"' \
--form 'txn_s2s_flow="1"' \
--form 's2s_client_ip="192.x.x.x"' \
--form 's2s_device_info="Mozilla Browser"' \
--form 'pg="EMI"' \
--form 'bankcode="BAJFIN03"' \
--form 'ccnum="2030400291909002"'
```

Redirect the customer to the bank page using the **acsTemplate** as received in [Step 2](#step-2-initiate-the-payment).
