This section describes how to link your WhatsApp Business Account with PayU (Self-Owned).

<Callout icon="📘" theme="info">
  **Note**: You must have merchant account with PayU and the merchant account must be verified or onboarding must be completed before you proceed with the steps in this section. For more information, refer to [Register for a Merchant Account](doc:register-for-a-merchant-account-on-dashboard) and [Activate Account](doc:complete-your-kyc).
</Callout>

To link your PayU merchant account with WhatsApp Business Account:

1. Log on to your WhatsApp Manager.
2. Select **Payment Methods** > **India** from the menu on the left pane.

<Image align="center" border={true} width="200px" src="https://files.readme.io/aa35f60-WhatsApp-Manager-Menu.png" className="border" />

3. Click **Add direct pay method** at the top-right corner.

<Image align="center" src="https://files.readme.io/7f08f55-WhatsApp-Manager-Payment-Methods-page.png" />

The _Add payment method_ wizard is displayed on a pop-up page.

<Image align="center" border={true} width="412px" src="https://files.readme.io/7d479b0-WhatsApp-Manager-Add-Payment-Method-popup.png" className="border" />

4. Enter the following details on the _Add payment method_ pop-up wizard.

| Field                      | Description                                                                                                                                             |
| :------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------ |
| WhatsApp Account ID (WABA) | Enter your WhatsApp account ID provided by WhatsApp.                                                                                                    |
| Payment method name        | Enter the name that must be displayed on order detail for the PayU payment method.                                                                      |
| Merchant Category Code     | Select your merchant category code from the drop-down list. PayU recommends you to select the Merchant Category Code that is inline with your business. |
| Purpose code               | Select the purpose code from the drop-down list. PayU recommends you to select the purpose code that is inline with your business.                      |

5. Click **Next**.

   The payment method type configuration page is displayed on wizard.

<Image align="center" border={true} width="422px" src="https://files.readme.io/e8b930c-whatapp-manager-choose-payment-gateway.png" className="border" />

6. Click **Payment gateway** in the **Choose a payment method type** field.

<Image align="center" border={true} width="422px" src="https://files.readme.io/e14074f-whatsapp-manager-choose-payu.png" className="border" />

7. Select **Payu** from the **Choose  a gateway to Integrate** drop-down list.
8. Click **Next**.

   The account password is request to confirm the new direct payment method.

<Image align="center" border={true} width="422px" src="https://files.readme.io/c6df04d-whatsapp-manager-enter-password.png" className="border" />

9. Enter your WhatsApp or Meta account password in the **Account password** field.
10. Read the WhatsApp's Privacy Policy and Payments Addendum and then click **Confirm**.

The progress is shown to redirect your to PayU.

<Image align="center" border={true} width="822px" src="https://files.readme.io/907d105-whatsapp-manager-redirect-to-payu.png" className="border" />

11. Click **OK**.

You will be redirected to PayU Dashboard login page.

12. Enter your PayU credentials and click Login. For more information, refer to [Log in to Dashboard](doc:log-in-to-dashboard).  
    ![](https://devguide.payu.in/wordpress/index.php/wp-json/getobject?keyname=uploads/2022/07/Screenshot-2022-07-11-at-7.48.37-PM-1-1024x629.png)  
    A page similar to the following is displayed to confirm the integration with WhatsApp.

<Image align="center" src="https://files.readme.io/308d65c-WhatsApp-Manager-redirect-back-to-Whatsapp.png" />

13. Click **Back to WhatsApp**.

A list of payment gateway configuration is displayed.
