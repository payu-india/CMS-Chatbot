You can create Payment Webhooks to recieve notification for Payment events. 

## Webhook events for Payments

| Event Name   | Description                                                               |
| :----------- | :------------------------------------------------------------------------ |
| `Successful` | Subscribe to this event to recieve notification for a successful payment. |
| `Failed`     | Subscribe to this event to recieve for a failed payment.                  |
| `Refund`     | Subscribe to this event to recieve for a payment refund.                  |
| `Dispute`    | Subscribe to this event for a payment dispute.                            |
