This section describes how to upload child merchants in bulk for onboarding into Split Settlements.

## Prerequisites

* Download the sample file as in the below [procedure](#procedure) (Step 1 to 3) and update it to include the data to be uploaded.
* Ensure that all mandatory fields in the file are filled with the correct details. The columns in the Excel sheet for upload are described.

## Procedure

To upload child merchants in bulk:

1. Select **Split & Supplier Payments** on the menu.

   The *Split Payments Overview* page is displayed.

<Image align="center" className="border" border={true} src="https://files.readme.io/963ee09eec42198183bc186ba1dcd97faf9ec8edc0fbaffe0325a5fffc4fc09d-split_sett_bulk_upload_menu.png" />

2. Click **New Sub-Merchant** at the top-right corner and select **Bulk Merchant Upload**.

   The *Merchant Bulk Upload* page is displayed.

<Image align="center" className="border" width="320px" border={true} src="https://files.readme.io/5af6164e9dcd94b18ec656c6bf705a8dd5cb353a8b3bfda771d790d73ccdd36e-split_sett_bulk_upload.png" />

> 📘 Note:
>
> Download the sample file for uploading the merchants using the **Download Sample File** button and update to include the merchant details.  For more information, refer to [Prerequisites](#prerequisites).

3. Click **Choose file** and select the file containing all the mandates that need to be debited. This file should follow the format outlined in the provided sample file. For more information, refer to [Prerequisites](#prerequisites).
4. Click **Upload**.

After uploading the file, the system will automatically check for discrepancies. If there’s an issue, an error message is displayed on the screen.

<Image align="center" className="border" width="320px" border={true} src="https://files.readme.io/889608ab8e9b8390af21b4aac650b56a68f012462934b8097bf510b6aaec654a-split_sett_bulk_upload_child_merchants.png" />

After your file is successfully uploaded, a message similar to the following screenshot is displayed.

<Image align="center" className="border" width="320px" border={true} src="https://files.readme.io/87a9a722b1f008c0cb848139950979e5dc3105db675f38f63561f66ce7bda7a6-split_sett_bulk_upload_success.png" />

5. Click **OK, Got it** and then you will be redirected to the *Sub Merchant* listing screen.
