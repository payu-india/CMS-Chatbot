After adding sub-accounts, you can remind child merchants to submit their bank account details whose details are incomplete.

To send a reminder to the child merchant or sub-account to submit bank details:

1. Navigate to the **Manage Sub-accounts** page.
2. Select the sub-account entry that has bank account details incomplete.

   The details of the sub-account are displayed similar to the following screenshot:

3. Click the reminder button next to **Details Pending**.

   A pop-up page similar to the following screenshot is displayed:

        null,
        ""

      "sizing": "350px"
    }
  ]

4. Perform any of the following steps to remind the child merchant:
   - Share the link using the copy button.
   - Enter the email ID of the child merchant and click **Send**.
