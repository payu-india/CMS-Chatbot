To view a split transaction details:

1. Login to the Merchant Dashboard.
2. Navigate to **Transactions**.
3. Scroll or navigate and look for the split transactions. The split transaction has drop-down next to the date column.

5. Click the transaction number to view the complete details of the split.

   The _Transaction Details of #\<transaction number>_ page is displayed, where the \<transaction number> is substituted by the transaction number of the parent transaction.
